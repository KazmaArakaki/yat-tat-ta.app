プライバシーポリシー

制定日：2026年10月7日

  • 集めるのは、ログインの番号とスクワットの記録だけです。名前とメールアドレスは受け取りません。
  • 広告、分析、トラッキングには使いません。ほかの利用者にも見せません。
  • アプリの設定から、いつでも記録とアカウントをすべて消せます。

Kazma Arakaki（以下「運営者」）は、iPhone アプリ「Yat Tat Ta」（以下「本アプリ」）で利用者の情報をどう扱うかを、このポリシーで定めます。

1集める情報

情報中身
アカウントの番号Apple でログインしたときに、Firebase Authentication が割り当てる利用者 ID と、Apple から受け取るログイン用の識別子。名前とメールアドレスは Apple に求めず、受け取りません。
スクワットの記録記録1件ごとの、叩き始めた日時、記録日、スクワットの回数、フィーバータイムで取ったドパの数、サーバーが記録を受け取った日時。
通信に伴う情報本アプリが Firebase と通信するとき、IP アドレスや端末の種類などの技術的な情報が、Google のサーバーで処理されることがあります。運営者がこれらを利用者ごとに集めて使うことはありません。

端末の中だけに置く情報

目標回数、今日まだ通知の設定、画面に一度出したお知らせの印は、iPhone の中だけに置き、外へ送りません。今日まだ通知も、iPhone の中で予約して出します。

2使う目的

  • スクワットの記録を保存し、機種を変えたときやアプリを入れ直したときにも、同じ記録を表示するため。
  • ログインした状態を保ち、記録をその利用者だけが読み書きできるようにするため。
  • 不正な利用を防ぎ、本アプリを安全に動かすため。

これ以外の目的には使いません。広告の表示、利用状況の分析、ほかのアプリやウェブサイトをまたいだトラッキングには使いません。

3情報を預ける先

集めた情報は、Google LLC（米国）が提供する Firebase に保存を委託しています。

  • Cloud Firestore：スクワットの記録を保存します。保存場所は東京（asia-northeast1）です。
  • Firebase Authentication：アカウントの番号を管理します。日本国外を含む Google のデータセンターで処理されることがあります。

Google LLC は、米国にある事業者です。米国の個人情報の保護に関する制度は、個人情報保護委員会のウェブサイトで確かめられます。Google は、Firebase で預かる情報について、データ処理の条件で安全管理の措置を定めています。

Apple でのログインは、Apple が提供する仕組みです。Apple による情報の扱いは、Apple のプライバシーポリシーに従います。

上の委託を除き、法令に基づく場合を除いて、利用者の同意なく情報を第三者に提供しません。

4保存する期間と、消し方

情報は、アカウントがある間だけ保存します。

本アプリの設定シートで「アカウントを削除」を押すと、スクワットの記録とアカウントをすべて消し、Apple との連携も解除します。消した情報は元に戻せません。Google のシステムから完全に消えるまでには、一定の期間がかかることがあります。

ログアウトしても、記録は消えません。同じ Apple ID でログインし直すと戻ります。

5安全管理

本アプリと Firebase の通信は暗号化しています。保存した記録は、その記録を作った利用者のアカウントからしか読み書きできないように設定しています。

6開示、訂正、削除のご請求

ご自身の情報の開示、訂正、利用の停止、削除などをご希望のときは、下の問い合わせ先へご連絡ください。ご本人であることを確かめたうえで、法令に従って対応します。削除は、本アプリの「アカウントを削除」からもすぐに行えます。

7このポリシーの変更

このポリシーを変えるときは、このページで知らせ、制定日の下に改定日を書きます。
