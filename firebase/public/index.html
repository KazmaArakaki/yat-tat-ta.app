食後のスクワットのための iPhone アプリ

食べて、しゃがんで、連続タップ。

スクワットが終わったら、回数だけ画面を連続タップ。タップするたびに CHANCE、激熱!!、FEVER。最後の1打で筋肉確定。地味な20回が、毎回お祭りになります。

買い切り。広告なし、アプリ内課金なし。ログインもいりません。

how it works

やることは、3つだけ。

1

食べる

いつものごはん。何を食べてもいい。

2

しゃがむ

ごはんのあとに、その場でスクワット。回数は5〜100回で、自分で決める。

3

連続タップ

しゃがんだ回数だけ、画面をタップ。スクワット1回が1ドパになって、記録に残る。

features

続けたくなる仕掛け。

CHANCE、激熱!!、FEVER、筋肉確定。

叩くたびに音と光が強くなって、最後の1打でドンと決まる。ときどき5秒間の FEVER が来て、叩いた分だけドパが増える。

+42ドパ

続けた日と、休み券

叩いた日が1日ずつ伸びる。7日続けるたびに休み券を1枚。休んだ日を、自動でつなぐ。

ドパがたまる

スクワット1回が1ドパ。7日間の DPW と、これまで全部の DT。

今日の記録を、カードにして貼れる

叩き終わったら、LINE や X に。7日分のマスと、続けた日数が1枚になる。

faq

よくある質問

料金は？

買い切りです。広告も、アプリ内課金もありません。

ログインは必要？

いりません。最初の起動で、すぐ叩けます。記録はアプリが最初の起動で作るアカウントに残ります。

iPhone を替えたら、記録はどうなる？

設定から Apple でログインしておけば、新しい iPhone でも同じ Apple ID でログインすると戻ります。

何回しゃがめばいい？

はじめは20回。設定で5〜100回のあいだで変えられます。

電波がないと使えない？

電波が要るのは、はじめての起動だけです。2回目からは、電波がなくても叩けます。

対応している機種は？

iOS 26 以降の iPhone です。

記録とアカウント

  • ログインしなくても、すぐに使えます。記録は、アプリが最初の起動で作るアカウントに残ります。
  • 設定シートから Apple でログインすると、iPhone を替えても、同じ Apple ID でログインすれば記録が戻ります。
  • 記録とアカウントは、アプリの設定シートの「アカウントを削除」（ログインしていなければ「記録をすべて削除」）から、すべて消せます。
