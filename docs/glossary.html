#dopa-apps

ドパ〇〇

ドリル、電卓、九九、タイピング、将棋のような普通の道具に、パチンコやお祭り級の過剰な演出をかぶせたネタ寄りのアプリ群。操作するたびにドーパミンが出るよう設計されている。名前は「ドパ」＋元の道具名。2026年9月下旬に個人開発とAIの界隈で連鎖的に量産された。

用例

開発者ドパ〇〇って、学習をゲームにしたアプリのことですか。

ドメインエキスパート中身は普通の道具のままです。ドリルは普通に採点するし、電卓は普通に計算します。そこに過剰な演出をかぶせたものです。

開発者演出を全部外せば、元の道具に戻るということですね。

ドメインエキスパートはい。ドパ将棋！だけは例外で、演出ではなく手番をなくすというルールの側でドパを出しています。

#dopagaki

ドパガキ

ドーパミン＋ガキ。ショート動画、通知、ガチャなどの即時報酬に弱い若者を、自虐的に指すZ世代のスラング。2025〜2026年に拡散した。派生語に「ドパる」「ドパ舌」がある。ドパ〇〇という名付けの下地になった。

用例

開発者ドパガキは他人を馬鹿にする言葉ですか。

ドメインエキスパート若者が自分たちを指して使う自虐語です。

開発者アプリの中で直接使われている例はありますか。

ドメインエキスパートドパ将棋！が、対局後に「ドパガキ度」を診断します。

#dopa-value

ドパ値

ドパドリルで正解するともらえる報酬の数値「ドパ」。内部では常用対数 L で持ち、表示は 10L。1万以上は「万」「億」で表記する。100、1000、1万から1億までの節目で演出が入り、上限は 109.08（約12億）。

用例

開発者ドパ値が億まで行くなら、そのまま整数で持つんですか。

ドメインエキスパート内部は対数 L です。画面に出すときだけ 10 の L 乗にして、「万」「億」で書きます。

開発者上限はありますか。

ドメインエキスパート10 の 9.08 乗で止まります。節目の演出は 100 から 1億まで、桁が上がるたびに入ります。

#effect-inflation

演出インフレ

1回のセッションの中で、進むほど演出が強くなっていくこと。ドパドリルでは演出強度を E = 0.08 + 0.92 × (i/(N−1))1.3 で決め、序盤は基本描画だけ、中盤で背景変化やはなまる、紙吹雪、星、終盤で花火や観客、行進、電飾、揺れを出す。最後は4種のフィナーレ（巨大ドパキチ、花火大会、ロケット、パレード）で終わる。

用例

開発者1問目から花火を出す設計にはしないんですか。

ドメインエキスパートドパドリルの仕様では、序盤は基本描画だけです。花火は終盤まで取ってあります。

開発者強さは問題数に比例して上がりますか。

ドメインエキスパート指数が 1.3 なので、比例より遅く立ち上がって、最終問で 1.0 に届きます。

#combo-multiplier

コンボ倍率

連続正解（コンボ）の数に応じて報酬を増やす倍率。ドパドリルでは M(c) = 1 + min(1, c/20)。10コンボで1.5倍、20コンボ以上で「ドパ×2 MAX」になる。倍率とは別に、10、20、30、50、75コンボで大きく祝う。ドパにゃんでは30コンボで FEVER、60コンボで「マタタビモード」に入る。

用例

開発者30コンボなら3倍ですか。

ドメインエキスパート20コンボで2倍に届いたら、そこで止まります。表示は「ドパ×2 MAX」です。

開発者じゃあ20コンボを超えたら何も起きない？

ドメインエキスパート倍率は変わりませんが、30、50、75コンボで大きく祝う演出が入ります。

#kakutei-enshutsu

確定演出／煽り演出

パチンコの文法を借りた演出。煽り演出は結果を見せる前に段階を踏んで期待を高めるもので、ドパ電卓は NORMAL、CHANCE、激熱、PUSH、シャッター、暗転、復活、PREMIUM と進む。確定演出は到達が決まったことを告げるもので、ドパ九九の「虹ドパ」が当たる。語彙として先バレ、激熱、PUSH、虹がよく使われる。

用例

開発者電卓の答えはランダムじゃないですよね。ドパ電卓は何を煽っているんですか。

ドメインエキスパート答えは普通の計算どおりです。上がるのは演出のランクだけ。結果が 7、77、777、7777、8192 なら強制で PREMIUM です。

開発者結果が 0 のときは？

ドメインエキスパート「全消灯」です。

#fixed-vs-variable-reward

確定報酬と可変報酬

確定報酬は、行動すれば必ず決まった報酬が入る仕組み。可変報酬は、報酬が出るかどうかや量が毎回ぶれる仕組みで、スロット型と呼ばれる。分析者はドパドリルを「確定報酬のセッション内増幅」とし、可変報酬とは違うと評している。ドパドリル系は課金、ランキング、可変報酬を持たない。

用例

開発者ドパドリルって、仕組みはガチャと同じですか。

ドメインエキスパート分析者は違うと見ています。正解すれば必ずドパが入る確定報酬で、それが1回の中で増幅していくだけです。

開発者それなら依存の批判はかわせますか。

ドメインエキスパート課金もランキングもないとは説明できます。ただ、子ども向けで依存を煽る設計だという批判は受けうると考えておいてください。

#reduced-effects-mode

ひかえめモード

過剰な演出を抑えるための安全弁。ドパ九九の「ひかえめ」モードがこの名の由来。ドパ九九はあわせて明滅を1秒3回まで、粒子を800個（スマホは400個）までに制限している。ドパ電卓の Reduce Motion 対応も同じ役割の仕組みとして扱う。

用例

開発者ドパ九九の安全配慮は、ひかえめモードだけですか。

ドメインエキスパートほかに、明滅を1秒3回までにして、粒子も800個、スマホでは400個までにしています。

開発者ドパ電卓には同じものがありますか。

ドメインエキスパート名前は違いますが、Reduce Motion に対応しています。

#vibe-coding

バイブコーディング

生成AIに指示してアプリを作らせる作り方。ドパ〇〇はこの界隈で量産された。ドパドリルは作者が Opus 5.5 を試すために作ったもので、演出、効果音、BGM まで生成している。音を Web Audio で合成して外部素材を持たないため、AIの1回の生成で完結しやすい。

用例

開発者ドパ〇〇がバイブコーディングと相性がいいのはなぜですか。

ドメインエキスパート音を外部ファイルではなく Web Audio で合成するので、素材を用意しなくても1回の生成で動くものができやすいんです。

開発者作った人たちの動機は？

ドメインエキスパートドパドリルの作者は Opus 5.5 を試すためだったと書いています。演出を盛るのはAIの見せ場になる、という見方もあります。
