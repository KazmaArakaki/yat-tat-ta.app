iOS プロジェクトの設定

2026-10-06 決定。プロジェクトの設定を変えるとき、ビルド設定で迷ったときに開く。

決まり事

設定は ios/project.yml に書く。Xcode の画面では変えない。
Xcode で変えた設定は、次の xcodegen generate で消える。

最小対応 iOS（Minimum Deployments）
26.0
Bundle Identifier
com.yat-tat-ta
ストア公開後は変更不可。
対応端末
iPhone のみ
署名チーム（Developer Team）
K334V22YZ3
開発者個人名義。自動署名。

layout

ファイルの置き場所

yat-tat-ta/
├── docs/
└── ios/
    ├── project.yml          # 設定の本体。コミットする
    ├── YatTatTa/            # Swift のソースとアセット
    └── YatTatTa.xcodeproj   # 生成物。コミットしない

ターゲット名 YatTatTa は仮。ホーム画面のアプリ名は未定（課題 app-display-name）。

project.yml

設定ファイルの中身

作成時の予定。実物ができたら、そちらが正。

name: YatTatTa
options:
  deploymentTarget:
    iOS: "26.0"
targets:
  YatTatTa:
    type: application
    platform: iOS
    sources: [YatTatTa]
    settings:
      base:
        PRODUCT_BUNDLE_IDENTIFIER: com.yat-tat-ta
        DEVELOPMENT_TEAM: K334V22YZ3
        CODE_SIGN_STYLE: Automatic
        GENERATE_INFOPLIST_FILE: YES
        # iPhone のみ
        SUPPORTED_PLATFORMS: "iphoneos iphonesimulator"
        TARGETED_DEVICE_FAMILY: "1"
        SUPPORTS_MACCATALYST: NO
        SUPPORTS_MAC_DESIGNED_FOR_IPHONE_IPAD: NO
        SUPPORTS_XR_DESIGNED_FOR_IPHONE_IPAD: NO

iphone only

「iPhone のみ」が指す範囲

端末扱いどこで決まるか
iPhone対象TARGETED_DEVICE_FAMILY = 1
iPadiPad 向け画面は作らない。ただし iPhone サイズのまま入れられる（Apple の決まりで止められない）同上
Mac対象外ビルド設定の SUPPORTS_MAC… と、提出時の App Store Connect
Vision Pro対象外SUPPORTS_XR…

generate

生成と実行

Mac 側で行う。初回だけ 1 が要る。

  1. 1

    XcodeGen を入れる

    brew install xcodegen
  2. 2

    .xcodeproj を作る

    project.yml を変えたとき、ファイルを足したときも実行する。

    cd ios && xcodegen generate
  3. 3

    実機で動かす

    ios/YatTatTa.xcodeproj を Xcode で開き、実行先を iPhone にして ▶。
