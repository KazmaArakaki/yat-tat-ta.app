layout

ファイルの置き場所

yat-tat-ta/
├── docs/
└── ios/
    ├── project.yml              # 設定の本体。コミットする
    ├── YatTatTa/                # Swift のソースとアセット
    │   ├── YatTatTaApp.swift    # 起動。SwiftData の入れ物を作る
    │   ├── Model/               # 記録（SquatRecord）、記録日、記録からの計算（Ledger）、節目
    │   ├── Mash/                # 叩いている途中の状態、画面が読む状態（AppModel）、端末の設定
    │   ├── Feel/                # 音と振動、声と効果音の一覧
    │   ├── Sounds/              # 声と効果音のファイル（開発者が用意）
    │   ├── Home/                # ホームと、上に重ねる部品
    │   ├── Settings/            # 設定シート
    │   ├── Reminder/            # 今日まだ通知の予約
    │   ├── Theme/               # 色と文字
    │   ├── Localizable.xcstrings # 画面の文言
    │   └── Info.plist           # INFOPLIST_KEY_ で書けないキーだけ
    ├── YatTatTaTests/           # 計算と AppModel のテスト
    └── YatTatTa.xcodeproj       # 生成物。コミットしない

ターゲット名 YatTatTa は、アプリ名 Yat Tat Ta から空白を抜いた形（Swift のモジュール名に空白とハイフンは使えない）。ホーム画面に出る名前は INFOPLIST_KEY_CFBundleDisplayName で別に決める（2026-10-06 アプリ名を決める）。

info.plist

Info.plist に書く値

Info.plist の値は、まず project.yml に INFOPLIST_KEY_〇〇 として書く。Xcode がこの形で受け付けるのは決まったキーだけで、それ以外を書いても黙って無視される。無視されたキーだけを ios/YatTatTa/Info.plist に書く。ビルド時に、生成された値とマージされる。

キー値理由
CADisableMinimumFrameDurationOnPhonetrueProMotion の iPhone で、アニメーションを 60Hz に絞らず 120Hz で描く（2026-10-06 手触りの試作）

効いたかどうかは、ビルドした .app の中の Info.plist で確かめる：plutil -p YatTatTa.app/Info.plist

generate

生成と実行

Mac 側で行う。初回だけ 1 が要る。

  1. 1

    XcodeGen を入れる

    brew install xcodegen
  2. 2

    .xcodeproj を作る

    project.yml を変えたとき、ファイルを足したときも実行する。

    cd ios && xcodegen generate
  3. 3

    実機で動かす

    ios/YatTatTa.xcodeproj を Xcode で開き、実行先を iPhone にして ▶。

  4. 4

    テストを流す

    記録からの計算を変えたら必ず流す。Xcode なら ⌘U。

    cd ios && xcodebuild test -project YatTatTa.xcodeproj -scheme YatTatTa -destination 'platform=iOS Simulator,name=iPhone 17'
  5. 5

    演出を叩かずに出す（Debug ビルドだけ）

    シミュレーターでは連打できないので、起動引数で演出の画面を出す。名前は chance、hot、push、reels、gold、kakutei、negirai、heavy（一番重い場面）。Xcode なら Scheme の Run の Arguments に -demo heavy のように足す。

    xcrun simctl launch --terminate-running-process booted com.yat-tat-ta -demo kakutei
  6. 6

    声と効果音を足す

    ios/YatTatTa/Sounds/ に、決まったファイル名（voice_chance.wav など。一覧は Feel/Sound.swift）で置き、xcodegen generate をやり直す。置いていないものは、合成音か端末の読み上げで代わりに鳴る。

troubleshooting

ハマりどころ

症状原因対処
None of the input catalogs contained a matching … app icon set … named "AppIcon"XcodeGen は既定でアイコン名 AppIcon を設定する。Xcode 27 の雛形の Assets にはアイコンがないASSETCATALOG_COMPILER_APPICON_NAME: ""。アイコンを作ったら名前を入れる
コマンドラインでビルドしても、Localizable.xcstrings に新しい文言が入らない文言を String Catalog に書き足すのは Xcode の画面だけ。xcodebuild は書き出し用の .stringsdata を作るところまでXcode でビルドする。コマンドラインだけで済ませるなら、ビルドのあとに find ~/Library/Developer/Xcode/DerivedData/YatTatTa-*/Build/Intermediates.noindex/YatTatTa.build -name '*.stringsdata' | grep -v -e AppShortcuts -e GeneratedAsset | xargs xcrun xcstringstool sync YatTatTa/Localizable.xcstrings --stringsdata
