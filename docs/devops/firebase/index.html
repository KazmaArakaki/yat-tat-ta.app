Firebase の準備と運用

2026-10-07 設計。Firebase の設定を触るとき、記録の列を変えるとき、ルールを変えるときに開く。

決まり事

  • Firebase で使うのは、Authentication（Apple のログイン）と Firestore の2つだけ。
  • GoogleService-Info.plist は Git に入れない。
  • テストと計測モードは Firestore に触れない。メモリ版の RecordStore を使う。
  • 記録の列を足したり変えたりしたら、同じコミットでルールも直し、反映する。
置き場所
users/{uid}/records/{recordId}
列はSquatRecord。

setup

最初の準備（約35分）

開発者のアカウントでしかできない作業です。実装を始める前に1回だけ。

  1. 1
    Firebase のプロジェクトを作る（約10分）
    Firebase コンソールでプロジェクトを作る。Google アナリティクスは入れない（集める理由がなく、プライバシーの表示が増える）。iOS アプリを足し、バンドル ID に com.yat-tat-ta を入れる。
  2. 2
    設定ファイルを置く（約2分）
    ダウンロードした GoogleService-Info.plist を ios/YatTatTa/ に置く。.gitignore に入れてあるので、Git には入らない。ないままビルドすると、起動した瞬間に落ちる。
  3. 3
    Firestore を作る（約5分）
    Firestore Database を作る。場所は東京（asia-northeast1）。あとから変えられない。始めは本番モード（全部断る）で作り、すぐ下のルールを反映する。
  4. 4
    Apple のログインを有効にする（約15分）
    Authentication の Sign-in method で Apple を有効にする。Apple Developer の Keys で Sign in with Apple の鍵を作り、Team ID（K334V22YZ3）、鍵の ID、鍵のファイルを Firebase の Apple の欄に登録する。この鍵がないと、アカウントを削除するときに Apple との連携を切れない。
  5. 5
    ルールを反映する（約3分）
    リポジトリの firebase/ で firebase deploy --only firestore:rules を実行する（Firebase CLI）。ルールを変えたら、そのたびに反映する。

security rules

ルール

アプリに埋め込む鍵は、誰でも取り出せます。他人の記録を読ませない、壊れた記録を書かせないのは、このルールです。置き場所は firebase/firestore.rules。

createdAt はサーバーの時刻（serverTimestamp）でしか書けません。電波のないところで叩いた記録も、送られた時点でサーバーが時刻を入れるので、ルールを通ります。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isValidRecord(d) {
      return d.keys().hasOnly(['startedAt', 'day', 'reps', 'bonusDopa', 'createdAt'])
        && d.keys().hasAll(['startedAt', 'day', 'reps', 'bonusDopa', 'createdAt'])
        && d.startedAt is timestamp
        && d.day is int && d.day >= 20260101 && d.day <= 99991231
        && d.reps is int && d.reps >= 1 && d.reps <= 1000
        && d.bonusDopa is int && d.bonusDopa >= 0
        && d.createdAt == request.time;
    }

    // 自分の棚だけ。記録は足すか消すだけで、書き換えない
    match /users/{uid}/records/{recordId} {
      allow read, delete: if request.auth != null && request.auth.uid == uid;
      allow create: if request.auth != null && request.auth.uid == uid
        && isValidRecord(request.resource.data);
      allow update: if false;
    }
  }
}
