devops

開発と運用の決まり事。環境を作り直すとき、困ったときに開く。

開発環境

  • iOS 開発環境

    Mac・Xcode・iPhone の構成、作り直す手順、ハマりどころ。

  • iOS プロジェクトの設定

    最小対応 iOS、Bundle Identifier、iPhone のみの設定。XcodeGen の project.yml で管理する。

サーバー

  • Firebase の準備と運用

    Firebase のプロジェクト、Firestore、Apple のログインの準備。ルールの置き場所と反映のしかた。

確かめ方

  • 処理落ちの確かめ方

    計測モード（-perf）で一番重い100打を叩き、描画、タッチ→発火、途中で切った音を合格の線と比べる。

文言

  • 多言語の決まり事

    日本語と英語で出す。訳語表（アプリの言葉、演出の言葉）、英語の声の台本、英語のストアの説明文。

  • 健康効果の書き方

    画面には書かない。ストアに書いてよい1文と、どこにも書かない言葉。注意書きの文面と、出典。

  • App Store の掲載情報

    説明文、キーワード、年齢制限の答え（9+）、審査メモ、スクリーンショットの6枚と撮り直し方。パチンコの語を書かない決まり。

発信

  • SNS で発信するときの決まり事

    健康の効果とパチンコの語を書かない。頼んだ投稿には PR。主役はスクワットマン。レビューと引き換えに何も渡さない。出す直前の点検5つ。

  • 健康効果の書き方

    SNS の投稿は、ストアのキーワードと同じ扱い。研究の1文も書かない。

素材

  • 声と効果音の出どころ

    27ファイルの出どころ（Gemini 3.8 Flash TTS と ElevenLabs の有料プラン）と、商用で使ってよい理由。足すときの手順。
