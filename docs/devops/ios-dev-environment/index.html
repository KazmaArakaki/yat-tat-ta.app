setup

セットアップ手順

Mac を替えたとき、作り直すときはこの順で。Xcode のダウンロード待ちを除けば 30 分ほど。

  1. 1Apple ID で Mac にサインインしておく。システム設定の左上に名前が出ていればよい。

  2. 2App Store から Xcode をインストールする。空き容量は 40GB 前後必要。

    初回起動で規約に同意し、プラットフォームで iOS を選ぶ。iOS Simulator（約 8GB）は、実機テストだけなら完了を待たなくてよい。

  3. 3コマンドラインのツールを Xcode に向ける。

    sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcode-select -p && xcodebuild -version

  4. 4Xcode → Settings（⌘,）→ Apple Accounts で Apple ID を追加する。チームが表示されれば OK。

  5. 5iPhone を USB で繋ぎ、「このコンピュータを信頼」を選ぶ。

    iPhone の 設定 → プライバシーとセキュリティ → デベロッパモード をオン。オフだった場合は再起動が入る。

    xcrun devicectl list devices

    State が connected なら繋がっている。

  6. 6Mac の Claude Code を確かめ、リポジトリで起動する。

    claude --version
cd <Mac 側の yat-tat-ta リポジトリ>
claude

  7. 7動作確認。Xcode で新規 App を作り、Signing & Capabilities の Team を設定する。実行先を iPhone にして ▶。

    iPhone でアプリが起動すれば完了。

troubleshooting

ハマりどころ

2026-10-06 の構築で実際に出たもの。

症状 原因 対処
xcode-select: error: tool 'xcodebuild' requires Xcode, but active developer directory '/Library/Developer/CommandLineTools' is a command line tools instance Command Line Tools が選ばれている 手順 3 のコマンドを実行
実行先の一覧で iPhone が Incompatible「OS version lower than…」 Xcode 27 の新規プロジェクトは Minimum Deployments の iOS が 27.0 General → Minimum Deployments の iOS を端末の iOS 以下にする（本番も 26.0。設定）。または iPhone を iOS 27 に上げる
File → New → Project に iOS タブがない Xcode 27 の新規作成画面は App / Command Line Tool / Package の3つだけ App を選ぶ。入力画面なしで Untitled Project（Mac / iPhone 両対応）ができる。名前と Team はあとから設定する
実機にアプリを入れられない Team が None のまま Signing & Capabilities で Team を選ぶ
