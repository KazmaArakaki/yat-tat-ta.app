出どころと使ってよい理由

出どころ使ってよい理由（2026-10-06 に規約で確認）クレジット表記
Gemini 3.8 Flash TTS
Gemini API		規約に「生成したコンテンツの所有権を Google は主張しない」とある。Gemini API は、仕事や事業の目的で開発者が使うためのものとされている。要らない
ElevenLabs
有料プラン		規約で、有料プランの人は商用の目的で使ってよい。無料プランの人は非商用に限られるので、2026-10-06 に有料プランに入ってから生成した。有料プランなら要らない

規約はあとから変わることがある。ストアに出す前と、素材を足すときに、もう一度読み直す。ElevenLabs は、プランをやめたあとも、在籍中に作ったものを使い続けてよいかを申請の前に確かめる（2026-10-06 時点では未確認）。

how to add

足すとき、差し替えるとき

  1. 1
    出どころの規約で、商用で配ってよいかを確かめる。無料プランでは使えないところがある（ElevenLabs など）
  2. 2
    決まったファイル名で ios/YatTatTa/Sounds/ に置き、xcodegen generate をやり直す。頭と終わりの無音は、アプリが読むときに切る
  3. 3
    このページの表に、ファイル名、出どころ、取得日を書き足す
