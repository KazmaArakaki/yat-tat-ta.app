features/記録する

完了連打

スクワットを終えたら、その回数だけ画面の中央を叩く。叩くたびにスクワットマンが揃ってしゃがみ、1打ごとにスクワット1回が1ドパに変わる。記録を作るのは、アプリの中でこの機能だけです。

01 / overview

何を叩いているのか

毎食後スクワットでは、アプリはスクワットを数えません。数えるのは本人で、アプリが受け取るのは「終わった」という合図だけです。その合図を1回の押下ではなく、目標回数と同じ数の連打にしたのが完了連打です。20回しゃがんだら20打。

スクワットマンの上に出ている数は、まだドパに変えていないスクワットの数です。1打で1減り、その1がドパの粒になって飛んでいく。済ませたスクワットを、自分の指でドパに替える作業になります。アプリはスクワットをしたかを確かめません。他人と比べる場所がないので、ごまかして困るのは本人だけです。

表1　決まりごと

項目値理由
1打の重さスクワット1回 = 1ドパドパに使い道はない。回数と同じものを、ためていく数として見せる。
目標回数既定 20。設定で 5〜100、5刻み食後20回ほど、という開発者の動機から。叩き始めた時点の値をその記録の最後まで使う。
いつ叩けるかいつでも、何度でも間食や夜食のあとも記録したい。1日の上限は置かない。
複数の指1本ずつ1打に数える手触りの試作と同じ。指が触れた瞬間に受ける（離したときではない）。

01-2 / squad

叩く場所に立つスクワットマン

最初の版では、画面のまん中に金色の丸いボタンを置いていました。けれども丸は何の形でもなく、叩いているのがスクワットの記録だとは目で分かりません。2026-10-06 に開発者の注文で、ボタンをやめました。上の帯と下のカードのあいだを画面の幅いっぱいに叩けるようにして、そこにスクワットマンを立たせます。

指が触れた瞬間に、スクワットマンの全員が揃ってしゃがむ。指が全部離れたら立ち上がる。指を置いたままなら、しゃがんだまま止まります。本物のスクワットの、下で止まる一瞬に近い形です。1打が「しゃがんだ1回」に見えるようになりました。

叩く前のスクワットマンは、床に寝ています。短く触れただけでは数えず、0.5秒押し続けて起こすと、立ち上がって叩けるようになる。ポケットの中や、画面をかすめた指で記録が始まらないための一段です（2026-10-06、開発者の注文）。起こした指は数えず、起きてから触れた指が1打目になる。寝るのは、残りが0になった最後の1打で倒れ込むときだけ。叩かずに置いても、60秒止まって記録が閉じても、アプリを離れても起きたままです。動きの見本は長押しでスクワットマンを起こす。

表1-2　スクワットマンの決まり

項目決まり理由
叩く場所上の帯と下のカードのあいだ、画面の幅いっぱい丸いボタンより的が大きく、連打で指が外れない
人の絵横向きの人を、コードで描く（太い ink の線に色を重ねた棒人間）。画像のファイルは使わない立つ姿としゃがむ姿のあいだを、線の形ごと動かせる。画面の大きさを選ばない
動き指が触れた瞬間にしゃがむ（0.08秒）、指が全部離れたら立ち上がる（0.12秒）。スクワットマンの全員が揃ってしゃがむタップは触れた瞬間に受ける（手触りの試作の決まり）。立ち上がりを少し遅くして、しゃがんだ形を目に残す
増え方最初は1人。スクワット2回ごとに1人、手前の列から奥の列へ増える。上限は30人。増えた1人は跳ねて現れ、「+1人」と音が出る目標回数60で30人に届き、そこで止まる。51人では実機で音が乱れ、返事が遅れた奥の列ほど小さく描き、大勢に見せる
残りの数スクワットマンの上に大きく「スクワット 残り 13」。PUSH では「PUSH!」と 3、2、1ボタンの中にあった数を、スクワットマンの上へ移す
段階の色NORMAL は人ごとに gold、dopa、signal を回す。激熱で全員 dopa、PUSH で全員 gold。虹の先バレは、スクワットマンの後ろで回る虹の輪色が揃うと、スクワットマンがひとつになって盛り上がって見える
寝ている・起こす叩く前は1人が床に寝ていて、叩いても数えない。下の文言は「長押しで起こす」。0.5秒の長押しで、じたばたしながら上半身が起き、立って小さく跳ねる（短い音と振動）。途中で離すと寝直す。起こした指は数えない。VoiceOver ではダブルタップで起こす誤タップで記録が始まらないように。押している間の体の起き上がりが、進み具合の目盛りを兼ねる
閉じたあと叩き切ったら、最後の1打で倒れ込んで寝る（フィーバーが当たったら終わってから）。フィナーレのあと、スクワットマンは1人に戻る。途中で閉じたときは、1人に戻って起きたまま次の食事の連打は、また1人から。寝るのは叩き切ったときだけ

指の位置の輪、飛ぶドパの粒、飛ぶ「ドパ」の文字、叩き切ったときの粒の噴き出しは、ボタンのときから変えない。視差効果を減らす設定でも人はしゃがむ。動きが、叩いた返事そのものだからです。増えるときの跳ねだけを止める。決めた経緯は本作りの設計 04-5。

スクワットマンの上の「スクワット 残り」の数は、叩いている間パーティーパロット風に動く。色が虹の12色を1秒で1周し、数が小さく円を描いて揺れる。揺れは段階が上がるほど速い。数の大きさも叩くたびに少しずつ大きくなり、84pt から最後の1打で170pt になる。

02 / closing

記録が1件になるまで

最初の1打で、記録が1件開きます。叩くたびに画面の中のドパ、DPW、DT が1ずつ増え、開いた記録は次の3つのどれかで閉じます。閉じるまで記録は画面の中にだけあり、閉じた瞬間に1回だけ端末へ保存します。1打ごとに書き込むと、タップの瞬間の仕事が増えるからです。

閉じる 1

残りが0になった

最後の1打。フィナーレを出す。そのあと1.2秒は叩いても数えない。勢い余った指で次の記録が始まらないように。

閉じる 2

60秒叩かなかった

叩いたところまでで1件。フィナーレは出さず、残りの数は目標回数に、スクワットマンは1人に戻る。スクワットを終えてから叩くので、途中で1分空くのはやめたときだけ。

閉じる 3

アプリを離れた

ホームに戻った、電話が来た。2 と同じ閉じ方。離れたまま終了されても、叩いた分は消えない。

7打で止めた記録も、7ドパの1件として残り、その日の連続記録もつながります。継続の条件は「その日に完了連打を1回」で、目標回数に届いたかは問いません。閉じないまま待ち続けると、昼に7打で止めた人が夜に開いたとき、残りの数に「13」が残ってしまいます。

間違えて叩いた記録を消す仕組みはない（開発者が決定）。課題 undo-record。アプリが異常終了したときは、開いていた1件が消える。

03 / effects

1打ごとの演出と、最後の1打

演出は、ドパドリルの演出インフレと同じく、最後に向けて強くなります。強さの決め方は、出すものごとに分けています。音程を叩く速さで決めると、ゆっくり叩く人は最後まで低い音のままになる。かといって速さを捨てると、手触りの試作で「気持ちいい」と言われた連打の勢いが消えます。

表2　何で強さを決めるか

出すもの強さを決めるもの
音の高さ、振動の強さ進み具合。目標回数を8つに割り、何打目かで8段階のどれかを鳴らす。最後の1打がいちばん高く強い
指の位置の輪、四辺の光連打の速さ。0.45秒以内に次を叩くと明るくなり、止まると落ちる
ドパの粒いつも同じ。1打で1粒、指の位置から「+N ドパ」へ飛ぶ

残りが0になる1打では、フィナーレが重なります。粒が弾け、「やったった！」の文字、和音、長めの振動。その日最初の記録なら連続記録の日数がめくれ、節目に届いていれば札が1枚ずつ下に積まれます。節目の中身はドパの合計と連続記録と休み券に書いています。

  • 音：外部の音素材を持たず、起動時に8段階ぶん合成しておく。マナーモードでは鳴らさない（.ambient）。ほかのアプリの音楽は止めない。
  • 粒：CAEmitterLayer で出す。粒の動きを GPU 側で計算し、1打ごとのメインスレッドの仕事を増やさない。足りるかは課題 heavy-effects-performance で実機確認。
  • 視差効果を減らす：iPhone のこの設定が入っていれば、粒と画面の揺れを止め、数字の変化と輪だけにする（ひかえめモードの考え方）。

03-2 / dopadopa

連打の途中のドパドパ

上の表だけでは、20打のうち19打がほぼ同じ見た目で過ぎます。山は最後の1打にしかありません。そこで連打の途中に、パチンコの文法を借りた段階を置きます。これをドパドパと呼びます（開発者の注文から）。

パチンコは、当たるかどうか分からないから煽ります。完了連打は、叩き切れば必ずフィナーレが出る。外れがないので、段階はくじで決めず、何打目まで来たかで決めます。同じ目標回数なら、毎回同じ打で激熱が来ます。

表2-2　ドパドパの段階（目標回数 20 の場合）

段階入る1打入った瞬間その段階のあいだ、1打ごと
NORMAL1打目なし輪と粒。指の位置から小さな「ドパ」の文字が飛ぶ
CHANCE進み具合 30%（6打目）画面いっぱいに「CHANCE!!」。上がる音を1つ画面の四辺が dopa 色で脈打つ。「ドパ」の文字が大きくなる
激熱進み具合 60%（12打目）「激熱」の判子が押され、画面が1度揺れる。低い音と重い振動地が暗転して虹の放射線が回る。スクワットマンの全員が dopa 色になる。叩く音に低音を重ねる
PUSH残りが3になった1打（17打目）スクワットマンの上の文字が「PUSH!」になり、スクワットマンの全員が gold になる残りの数を 3、2、1 と大写しにする
確定最後の1打フィナーレ

目標回数が 10 より少ないときは、PUSH を残り1打にする。段階の入り口が同じ1打に重なったら、強いほうだけを出す。

  • 勢いの表示：0.45秒以内に叩き続けると、指の上に「ドパドパ ×N」と続いた打数が出て、飛ぶ文字が「ドパ」から「ドパドパ」に変わる。数は勢いを見せるだけで、ドパは1打で1のまま。コンボ倍率は付けない。付けると、1ドパが1回のスクワットでなくなる。
  • 虹の先バレ：最後の1打で節目に届くと記録から分かっているとき、PUSH に入った瞬間から、スクワットマンの後ろで虹の輪が回る（04-2 ではボタンの縁だった）。パチンコの先バレと同じく当たりを前もって告げるが、くじは引いていない。
  • 守るもの：画面全体の明滅は1秒に3回まで。「視差効果を減らす」が入っていれば、揺れ、集中線、飛ぶ文字を止め、段階の文字とスクワットマンの色だけを変える（ひかえめモードの考え方）。音と振動は変えない。

叩いて確かめられる見本は ドパドパの見本。決めた経緯は本作りの設計 04-2。

03-3 / fullscreen

画面ぜんぶが鳴る

ドパドパだけでは、まだ足りませんでした。集中線も判子もボタンのまわりで起き、上の帯と下のカードは激熱のあいだも静かなまま。パチンコの台には、そんな静かな場所はありません。そこで、段階の舞台を画面全体へ広げます。

表2-3　画面全体の段階（ドパドパの段階に重ねる）

段階画面の地1打ごと
CHANCE画面の四辺が dopa 色に光って脈打つ四辺の光が1打ごとに強まる
激熱地が暗転し、画面全体に虹色の放射線がゆっくり回る放射線が少しずつ速くなり、画面の端から火の粉が上がる

03-4 / kakutei

叩き切ったあとの3秒

最後の1打のあと、演出は2つ続きます。合わせて3秒ほど。04 の設計では2秒で終わっていたので、1秒伸びました。

1.2秒

筋肉確定

白い閃光のあと、虹の放射線の上に金属の文字が2行で落ちる。言葉は筋肉確定、太もも確定、根性確定、継続確定、明日も確定を、記録を閉じた順に回す。下に小さく「やったった！」と変えたドパ。

1.6秒

ねぎらい

画面が金の炎に包まれ、金の文字でねぎらう。節目の札はこの下に積む。言葉は下の表のとおり、その場の事情で選ぶ。

表2-4　ねぎらいの言葉（上から順に、当てはまった最初の1つ）

場面言葉
連続記録の節目に届いた「30日連続！あんたはえらい！」
その日の最初の記録「今日もお疲れ！」
21時から午前4時まで「夜食のあとに、えらすぎる！」
それ以外「あんたはえらい！」「よっ、太もも番長！」「限界突破！」を順に回す
  • 飛ばせる：叩き切って1.2秒が過ぎたら、画面のどこを触っても飛ばせる。次の食事のあとに急いで叩く人を待たせないため。
  • 途中で閉じた記録には出さない：叩き切った人へのねぎらいだから。届いた節目の札だけを出す。
  • 健康効果は言わない：「筋肉確定」は冗談の言葉で、体の中で起きることには触れない（健康効果の書き方）。

声と効果音は開発者に用意してもらい、届くまでは合成音で代える（本作りの設計 04-3 の表1-5）。叩いて確かめられる見本は 画面全体の演出の見本。

03-5 / fever

5秒のフィーバータイム

完了連打の1打ごとに、0.51% のくじを引きます。当たると、その1打の直後から5秒間のフィーバータイム。スクワットの残りは止まり、そのあいだは画面のどこを叩いても1打1ドパ入ります（倍率は付けない）。5秒で40打なら40ドパ。最後の2秒（ラッシュ）は演出だけが強まります。

Yat Tat Ta の演出は、段階も確定も、くじを引かずに決めてきました。フィーバーだけが例外です。いつ来るか分からないこと自体を、開発者はドーパミンの材料に選びました（可変報酬）。20打の連打で当たるのは約10回に1回、1日60打なら約4日に1回。外れが続いても、当たりやすくはなりません。

1打のドパ1打1ドパ。倍率は付けない1ドパの重さをスクワットとそろえる（開発者の注文）
