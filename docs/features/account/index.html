features/はじめる

アカウント

最初の起動で Apple でログインしてもらい、記録をその人のアカウントに残す。記録は Firestore に置くので、iPhone を替えても、アプリを入れ直しても、いずれ Android 版を出しても同じ記録が戻る。設定シートからログアウトとアカウントの削除ができる。2026-10-07 設計。

01 / rules

決まりごと

表1　アカウントの決まり
項目決まり理由
ログインするとき最初の起動で、ログイン画面から。ログインしないと叩けない全員の記録が必ずアカウントに残る（開発者が決定、2026-10-07）
ログインの手段Apple だけ。ボタンは「Appleで続ける」iPhone には Apple ID が必ずある。Firebase なら Android からも同じ Apple ID でログインできる
受け取るものFirebase が割り当てる番号（uid）だけ。名前とメールアドレスは求めない記録の持ち主が決まれば足りる。受け取らなければ、守るものも減る
2回目からの起動ログインしたまま。電波がなくても叩ける初めてのログインだけは電波が要る
同じ iPhone に入れ直したときログインしたまま始まる。Firebase がログイン状態をキーチェーンに残し、キーチェーンはアプリを消しても残る入れ直した人に、ログインし直してもらう理由がない。開発者が実機で確かめた（2026-10-07）
機種変更、入れ直し同じ Apple ID でログインすると記録が戻る。はじめての幕は端末ごとなのでもう一度出るが、チュートリアルは出ないチュートリアルは記録が1件もない人にだけ出す。記録が届くまで待ってから決める
ログアウト設定シートから。確かめてからログイン画面へ。端末のキャッシュは消す記録はアカウントに残る。同じ iPhone を別の人が使っても、前の人の記録が見えない
アカウントの削除設定シートから。確かめる、Apple でもう一度本人確認、記録をすべて消す、Apple との連携を切る、アカウントを消すApp Store の審査の条件。取り返しがつかないので2段で確かめる
叩いている最中ログアウトも削除も押せない閉じていない記録の行き先がなくなる
端末の設定目標回数、今日まだ通知、見せた印は端末に残す。ログアウトしても変わらない端末の持ち主の好みで、記録ではない
