features/はじめる

アカウント

記録の持ち主を決める。最初の起動では何も聞かずに匿名アカウントを作るので、ログインしなくてもすぐ叩ける。Apple でログインすると、そのアカウントに記録が残り、iPhone を替えても、いずれ Android 版を出しても同じ記録が戻る。記録は Firestore に置く。2026-10-07 設計、2026-10-08 改訂。

01 / history

ログインを最初に求めなくなった理由

2026-10-07 の設計では、ログインを一番前に置きました。全員の記録が必ずアカウントに残る、というのが開発者の決定で、ログインしないと叩けない作りです。審査の人には審査メモで理由（機種を替えても記録を戻すため）を書いておけば足りるはずでした。

2026-10-08、App Store の審査で断られました。理由はガイドライン 5.1.1(v)。「アカウントと関係ない機能を使うのに、登録やログインを求めてはいけない」。叩いて記録するのは、アカウントがなくてもできる機能です。理由を書いても、この決まりは越えられません。

そこで、起動したら Firebase の匿名アカウントを作り、ログイン画面を挟まずにホームへ進む形に変えました。記録の棚（users/{uid}/records）は匿名でも同じなので、Firestore のルールも記録の形も変わりません。Apple でのログインは設定シートへ移し、匿名アカウントを Apple ID へ引き継ぐだけにしました（開発者が決定、2026-10-08）。経緯はセッション：ログインせずに始めるにあります。

02 / rules

決まりごと

表1　アカウントの決まり
項目決まり理由
始めるとき最初の起動で、何も聞かずに匿名アカウントを作り、そのままホームへ。ログインしなくても全部使える叩いて記録するのは、アカウントがなくてもできる機能。App Store の審査で、登録を求めないよう求められた（ガイドライン 5.1.1(v)、2026-10-08）
はじめての起動に電波がないはじめの画面で待つ。「もう一度」で作り直す。つながったら、寝ていたスクワットマンが起き上がってホームへ匿名アカウントを作るのにだけ電波が要る。2回目からは電波がなくても叩ける
Apple でのログイン好きなときに、設定シートの「Appleで続ける」から。まだログインしていない人には、チュートリアルの記録を残す場面にも同じボタンを出す。匿名アカウントを Apple ID へ引き継ぎ、uid も記録もそのままログインする理由は、機種を替えても記録を戻すことだけ。叩くのには要らない
Apple ID に別のアカウントがあるとき「この Apple ID には、別の記録があります」と確かめてから、Apple ID のほうへ切り替える。匿名で付けた記録を消してから切り替える。空になった匿名アカウントは残す（消すには直前のログインが要り、匿名ではログインし直せない）。記録が0件なら確かめずに切り替える2つの棚を合わせる処理は作らない（開発者が決定、2026-10-08）。入れ直しや機種変更の直後で、捨てる記録は少ないはず
ログインの手段Apple だけ。ボタンは「Appleで続ける」iPhone には Apple ID が必ずある。Firebase なら Android からも同じ Apple ID でログインできる
受け取るものFirebase が割り当てる番号（uid）だけ。名前とメールアドレスは求めない記録の持ち主が決まれば足りる。受け取らなければ、守るものも減る
同じ iPhone に入れ直したとき前のアカウントのまま始まる。匿名でも Apple でも同じ。Firebase がログイン状態をキーチェーンに残し、キーチェーンはアプリを消しても残る開発者が実機で確かめた（2026-10-07、Apple のとき）
機種変更新しい iPhone は匿名アカウントで始まる。チュートリアルの記録を残す場面か設定シートで、同じ Apple ID でログインすると記録が戻る。チュートリアルの途中なら練習は記録を作らないので、確かめずに切り替わる。はじめての幕は端末ごとなのでもう一度出る匿名のままだった人の記録は、新しい iPhone へは持っていけない。前の iPhone の人を見分ける手がないので、記録を残す場面はまだログインしていない全員に出す（開発者が決定、2026-10-08。課題 guest-restore-hintへの対応）
ログアウトApple でログイン中の人だけ。設定シートから、確かめてから。端末のキャッシュは消し、新しい匿名アカウントで始まる記録は Apple のアカウントに残る。同じ iPhone を別の人が使っても、前の人の記録が見えない
削除Apple でログイン中の人は「アカウントを削除」。確かめる、Apple でもう一度本人確認、記録をすべて消す、Apple との連携を切る、アカウントを消す。匿名の人は「記録をすべて削除」。確かめてから、記録を消す。匿名アカウントも消すが、最後のログインから時間がたっていて消せなければ、空のまま手放す。どちらも、そのあと新しい匿名アカウントで始まるApp Store の審査の条件。取り返しがつかないので確かめる
叩いている最中ログイン、ログアウト、削除は押せない閉じていない記録の行き先がなくなる
端末の設定目標回数、今日まだ通知、見せた印は端末に残す。ログアウトしても、切り替えても変わらない端末の持ち主の好みで、記録ではない
