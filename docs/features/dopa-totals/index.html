ドパの合計

ためたドパを、2つの合計で見せる。これまでの全部の DT と、直近7日間の DPW。どちらも保存せず、記録から計算します。

01 / overview

何と並べて見せるか

ドパでは何も買えません。それでも数を2つに分けるのは、比べる相手が違うからです。DT は減ることがなく、次の節目までの距離で見せる。DPW は直近7日間の合計で、1週間前の自分と自己ベストで見せる。Duolingo の週のリーグから、他人を抜いて「1週間」という長さだけを借りた形です。曜日では区切りません。

Dopa Total

DT

  • 計算：すべての記録の回数を足す
  • 並べるもの：次の節目
  • 節目：100、1,000、10,000、100,000 ドパ

Dopa per Week

DPW

  • 計算：今日と前の6日の記録の回数を足す
  • 並べるもの：前の7日の合計、自己ベスト
  • 節目：自己ベストを超えた1打。1日に1回まで、記録を始めて8日目から

02 / calc

直近7日間は、どこからどこまでか

直近7日間は、今日の記録日と、その前の6日です。記録日は叩き始めた瞬間に決まり、午前4時より前なら前の日です。比べる相手の「前の7日」は、7日前から13日前まで。どちらも曜日とは関係なく、開いた日から数えます。前は月曜の午前4時で区切るつもりでしたが、それだと月曜の朝の DPW は1回分しかなく、何曜日に開くかで数字の重みが変わってしまう。いつ開いても同じ物差しで出せるよう、直近7日間に改めました（開発者が決定）。

そのかわり、DPW は叩かなくても減ります。午前4時を過ぎるたびに、7日前の1日分が区間から抜けるからです。7日前に60ドパためた人は、今朝開くと、まだ何もしていないのに DPW が60少ない。曜日で区切ったときのように、ある朝まとめて0になることはありませんが、「減った」と見える日は増えます。画面では減ったことを強調せず、数字をそのまま出します。

起動時に記録を全部読み、記録日ごとの合計を作ってから、7日ずつずらして足します。毎食後に3回叩いても1年で1,000件ほどなので、毎回最初から足しても間に合います。叩いている間は、画面の中の DT と DPW に1ずつ足すだけで、計算し直しません。

表1　DPW の自己ベストの決まりごと

場面扱い理由
自己ベストとは昨日までのどの日で区切った7日間の合計のうち、最大のもの今日を含めると、叩くたびに自分を超え続けてしまう。
超えた1打今日の DPW が自己ベストを1でも上回った打で、節目の札を出す並んだ瞬間ではなく、抜いた瞬間を祝う。
同じ日に2度目出さない超えたあとは1打ごとに更新になる。札が毎回出ては節目でなくなる。
はじめの7日記録を始めて7日目までは出さない。カードの自己ベスト欄は「—」7日まるごとたまった区間がなく、超える相手がいない。

DT の節目は、その打で DT が節目の数をまたいだときに1回だけ出ます。前回の3つ（100、1,000、1万）に10万を足しました。毎日60回で、5年足らずで届く距離です。札は完了連打のフィナーレの下に積まれます。途中で閉じた記録で節目をまたいだ場合も、またいだ1打で札を出します。

02-2 / dopa-toppa

100ドパごとの、ドパ突破

DT の節目は、100、1,000、1万、10万。毎食後に20回なら、100から1,000までは2週間ほど何も起きません。その間を埋めるのがドパ突破です。DT が100の倍数をまたいだ1打で、画面いっぱいに「300／ドパ突破」と出ます。

  1. 1金属の数字「300」が画面の中央に叩きつけられ、下に「ドパ突破」。叩く指は止めない。重ね物は指を通す
  2. 2文字のうしろで虹の放射線が回り、衝撃波の輪が画面の端まで広がる
  3. 31,000、1万、10万の節目では金になり、節目の札も出る

最初は、ここにスロットの「777」を回すドパ揃いを置いていました。開発者の注文で、2026-10-06 にやめています。リールが回って止まるまでの間は、連打の勢いとかみ合わなかった。突破した数字そのものを、その1打で叩きつけるほうが速い。

フィーバータイムの連打で100をまたいでも出します。1打1ドパなので、ふだんの連打と同じ速さで100に近づく。突破とフィーバーは関係がなく、突破したからといってフィーバーには入りません。

「視差効果を減らす」が入っているときは、放射線と衝撃波を止め、文字を置くだけにする。見た目は コンポーネント：ドパ突破。
