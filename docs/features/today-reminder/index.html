features/知らせる

今日まだ通知

その日まだ叩いていない夜に、1回だけ知らせる。頼まれてから出し、開かれなければ7日で自分から止まります（今日まだ通知）。

01 / why

責めずに知らせられるか

Duolingo の深夜の「連続記録が切れそう」通知は、効果が大きかったといいます。一方で、罪悪感をあおる作りは批判の的になりました。そして最も人を戻したのは、「この通知は効いていないようなので、しばらく止めます」という、やめると告げる通知でした。Yat Tat Ta は1人用で、通知から逃げる先がありません。出すなら、責めない形に縛ります。

  • 頼まれてから：初めて叩き切ったフィナーレのあとに1度だけ聞く。起動直後には聞かない。何をするアプリかも分からないうちに許可を求めても、断られるだけだから。
  • まだの日だけ、1日1回：既定は 21:00。その日に記録が1件でもあれば、その日の分は取り消す。
  • 7日で黙る：開かれるたびに先の7日分を予約し直す。7日目だけ文面が違う。

02 / schedule

届く時刻に、叩いたかを確かめられない

通知はサーバーを持たず、端末の中だけで出します。端末の中の通知は、届く瞬間にアプリを動かして「今日もう叩いたか」を確かめることができません。できるのは、先に予約しておき、叩いたら取り消すことだけです。

予約し直すのは、アプリが前に出たときと、記録が閉じたときです。どちらでも、予約を全部消してから、今日から7日分を入れ直します。今日の分は、記録がすでにあるか、時刻を過ぎていれば入れません。予約を7日分に限ったので、止める処理を別に書かなくても、開かれない限り7日で尽きます。

表1　文面（日ごとに順に回す）

順文面
1今日はまだです。食べたら、しゃがんで、叩く。
2{目標回数}回で{目標回数}ドパ。今夜のおやつのあとにでも。
3連続記録は、今日の1回でつながります。
41打で1ドパ。今日の分は、まだ0です。
7日目しばらく通知を止めます。また開いたら再開します。

文面には、予約した時点で分かる値（目標回数）しか入れません。連続日数を入れたくなりますが、7日先の連続日数は、その間に叩くかどうかで変わります。同じ文面が続くと効き目が落ちるという Duolingo の結果から、4つを日ごとに回します。文面は String Catalog に置き、多言語展開のときに訳せるようにします。

03 / settings

許可と設定

表2　状態と、どこで変わるか

値既定変わるところ
1度聞いたかまだ初めてのフィナーレのあとの問いかけ。「知らせて」でも「いらない」でも、聞いたことになる
ON/OFFOFF問いかけで「知らせて」を選び、iOS の許可が出たら ON。設定シートでいつでも切り替えられる
時刻21:00設定シート。変えたら、その場で予約し直す

設定シートで ON にしたとき、iOS の許可がまだなら、そこで許可を求めます。iOS の設定で通知を切られていたら、シートの切り替えの下に「iPhone の設定で通知が切られています」と出し、iOS の設定画面を開く導線を置きます。値はすべて UserDefaults に置きます。消えても既定の OFF に戻るだけです。
