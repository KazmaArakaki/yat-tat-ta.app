スプラッシュ

起動した瞬間に、これまで続けた日をスクワットマンの人形で並べ、空いている今日の席を見せる。1.65秒で、大きな数だけがホームの連続記録の帯へ飛んで終わる。叩けばその場で終わる。インストールして最初の1回だけは、14.0秒のはじめての幕で、これから毎日やることを1人の人形でやって見せる。2026-10-07 設計。

01 / rules

決まりごと

表1　出すときと出し方

項目決まり理由
出すときアプリを起動したとき。もう1つ、裏から戻ったときに記録日が変わっていたとき（その日いちばん初めに開いたとき）毎食後に開くたびに出すと、2回目からは待たされるだけになる。1日の最初の1回だけ、今日の席が空いていることを見せる
はじめての起動インストールして最初の1回だけ、はじめての幕（14.0秒、表3）を出す。見せたことは端末の設定（UserDefaults の introShown）に残し、2回目からはふつうの幕。記録がもうある人（はじめての幕より前から使っている人）には出さないまだ並べる日がない人に、これから並ぶものを先に見せる。毎回6秒は長いので、1度きり
出さないとき叩いている最中、フィナーレの途中、計測モード（-perf）、演出の確認用の起動引数があるとき連打と計測を止めない
長さ1.65秒。ひかえめモードでは1.15秒。はじめての幕だけ14.0秒。場面ごとに一呼吸おく起動の準備（記録の読み込みと音の用意）はこの間に済む。待たせた感じが出ない長さ
飛ばす画面のどこを叩いても、その場で引き継ぎ（最後の0.4秒）へ飛ぶ。はじめての幕では、1回叩くごとに次の場面の頭へ進む（一度に最後までは飛ばない）。どの1打もスクワットに数えない早く叩きたい人を待たせない。数えると、見ていない1打が記録に混ざる
隊列いまの連続の日を1日1人で並べる。7列で曜日にそろえ、古い日が左上、今日が右下。休み券の日は青い札。8週を超えたら古い週を「＋N日」にまとめる続けた日数を、数ではなく人数で見せる
今日の席今日まだなら、隊列の最後は人形がいない床の印で、上から薄い光が差している。今日済みなら、その印の上に人形が立っている。まだ1度も叩いていないときは、今日の席だけを大きく出す空きを埋められるのは今日の1回だけ、という形にする
途切れたあと前の連続の人形は並べない。今日の席だけを大きく出し、一言は最長記録失ったものを先に見せない（文言の決まり）
文言数と一言は、連続記録の帯と同じ文。次の1回で節目に届くなら「節目」の札引き継いだあとも同じ文が帯に残る。読み直さなくてよい
音と振動音は出さない。振動は Yat、Tat、Ta の3拍（弱、弱、中）開くのは食事のあと。店の中で起動の音が鳴ると困る。振動なら手の中で済む
VoiceOver幕全体を1つの要素にし、「Yat Tat Ta。29日連続。今日の1回で30日目。」と読む。読み終わるまで幕を残す隊列の形は聞いても分からない。1.65秒で切ると、読み上げが途中で消える
起動画面iOS が出す起動画面の地を、paper（暗い配色では #16120F）にするスプラッシュの地と同じ色にして、切り替わる瞬間のちらつきをなくす
ほかの重ね物途切れたときのカード、休み券の帯は、スプラッシュが消えてから出す2つ重ねると、どちらも読めない

表2　時刻（ふつうの場合）

秒起きること振動
0起動画面（地の色だけ）から、そのまま隊列と数が見えている—
0.15「Yat」が落ちる。隊列のいちばん古い日から、しゃがむ波が始まる弱
0.45「Tat」が落ちる。波は隊列のなかほど弱
0.75「Ta」が落ちる。波が今日の席に届き、dopa の輪が広がる。一言が出る中
1.25引き継ぎ。大きな数が帯の位置へ縮みながら飛び、ほかは消える—
1.65ホームだけになる—

表3　はじめての幕の時刻

秒起きること振動
0〜0.6地の色だけ。何も出さずに一呼吸—
0.6〜1.4「Yat」「Tat」「Ta」が0.4秒おきに落ちる（ふつうの幕の1.3倍の間）弱、弱、弱
1.4〜2.6名前だけを眺める間。最後の0.6秒で、名前が小さく上へ退く—
2.6まん中に大きな人形が1人、0.6秒かけて静かに立つ。言葉「食べて、」—
3.8言葉が「しゃがんで、」に替わる。人形は0.6秒で下り、0.2秒とどまり、0.6秒で上る—
5.4言葉が「連続タップ。」（dopa）に替わる。0.3秒おいて、足元から輪とドパの粒が0.9秒かけて広がる中
6.6〜7.0言葉が消え、人形だけが立っている。一呼吸—
7.0人形が0.9秒かけて縮み、今週の隊列の左端（今日）の席へ入り、すっと消える。光の差す床の印だけが残る—
8.0右へ明日からの席（床の印の輪郭だけ）が0.12秒おきに並ぶ。7つめは休み券の札。言葉「1日1回で、1人ずつ。」—
8.8明日からの6人が0.15秒おきに1人ずつ立って、しゃがむ。言葉「来週には、7人のスクワットマンになる。」—
10.4〜10.96人がいっしょに消える—
11.0言葉とほかの席が引き、今日の席がまん中へ寄って大きくなる—
12.0今日の席に輪が広がる。「最初の1回で1日目」。0.6秒おいて「1人目は、今日のあなたです。」中
12.6〜13.6そのまま。今日の席がゆっくり（1.8秒周期で）濃淡を繰り返す—
13.6〜14.0引き継ぎ。数「1」が帯へ飛ぶ—

動きはすべて、ゆっくり入ってゆっくり止まる曲線（sine）でつなぐ。言葉は1つずつ出し、前の言葉が消えてから次を出す。ひかえめモードでは、人形は動かさず、立つ姿としゃがんだ姿を切り替えるだけにする。輪、粒、明日からの6人は出さない。言葉と振動は同じ時刻のまま。

ひかえめモードでは、名前の落下、波、輪、飛ぶ数をやめ、全部を置いたまま0.9秒見せて、0.25秒で溶かす。振動の3拍は、ふつうの場合と同じ時刻に鳴らす（音と振動は変えない決まり）。

記録の保存の形は変わりません。端末の設定に、はじめての幕を見せたかどうか（introShown）を1つ足すだけです。隊列は連続記録の計算（Ledger.Streak の日数と休み券を使った日）からそのまま作ります。
