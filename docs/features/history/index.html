履歴

これまでの記録を、日付と時刻の上に人形で並べる。DPW と DT のカードは「どれだけ」を1つの数で見せるけれど、いつ叩いたかは見せません。履歴はその内訳です。2026-10-06 設計（開発者の手描きのラフから）。

01 / rules

決まりごと

表1　開き方と見え方

項目決まり理由
開くホームのDPWかDTのカードを押す。下から全画面のシートが出る。叩いている最中は押せないグラフの中身は、カードの数の内訳。ホームに部品を足さない。
横軸記録日。1日1列で、1画面に7日ほど。開いた直後は今日が右端。左へなぞると過去へ戻るDPW と同じ「直近7日」が最初に目に入る。
縦軸その日の時刻。下が午前4時、上が翌朝4時。3時間ごとに目盛り記録日の区切りに合わせる。夜食のあとの1件も、その日の列の上端に入る。
人形記録1件をスクワットマンのしゃがんだ人形1つで置く。面積をドパに比例させる（14〜46pt）。フィーバーのドパがある記録は dopa 色何時に、どれだけ叩いたかが1つの印で読める。
背景の面日ごとのドパ（dopa 色）と7日移動平均（signal 色）を、縁の線と薄い塗りで重ねる。斜線は使わない。同じ目盛りで、数字は出さない上下の激しい日ごとの量と、ならした1週間の調子を同時に見る。数は詳細で読む。
詳細人形を押すと、その人形が立つ⇄しゃがむを繰り返し（ひかえめモードではしゃがんだまま）、下にその記録の時刻、回数、フィーバーのドパ。上の行に、その日の件数、合計、7日移動平均グラフの上に数字を並べると人形が隠れる。
休み券の日休み券を使った日の列に、帯と同じ青い札を置く人形のない列が「途切れ」ではないと分かる。
見るだけ消せない。今日の1件を消すのは今日の記録から昨日より前を消さない決まり（今日の記録の設計）を崩さない。

保存するものは増えません。人形の位置は記録の叩き始めた時刻（startedAt）から、面の高さは記録を日ごとに足して出します。7日移動平均は、その日で終わる DPW を7で割った数です。記録を始める前の日は0ドパとして数えるので、始めて7日目までは低く出ます。
