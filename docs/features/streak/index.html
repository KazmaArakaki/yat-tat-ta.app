連続記録と休み券

完了連打をした日が何日続いたか。休んでも途切れない休み券と、途切れたときに何を見せるかも、この機能が持ちます。保存するものはなく、すべて記録から計算します。

01 / rules

続いたことにする条件

連続記録は、伸びている間は人を続けさせ、途切れた瞬間に逆に働きます。そこで、途切れにくくする仕組みと、途切れても残るものを一緒に置いています。条件の低さは Duolingo で最も効いた変更にならいました。

表1　決まりごと

項目決まり理由
続いた日その記録日に記録が1件以上ある。途中で閉じた7打の記録でもよい目標回数に届いたかを問わない。条件は低いほど続く。
1日の境目午前4時23時50分の夜食のあと、日付をまたいでしゃがんだ人が記録しそこねない。
休み券をもらう連続日数が7の倍数になった日に1枚。持てるのは2枚までDuolingo は通貨で買わせるが、ドパには使い道がない。上限2枚は Duolingo と同じ。
休み券を使う記録のない日に自動で1枚。その日は連続日数に数えない数えると、14日目に2枚もらった人が何もせず16日まで伸びる。
途切れる記録のない日に休み券がない。連続日数も休み券も0に戻る持ち越せると、次の連続を同じ持ち札で始められてしまう。

02 / walk

休み券を保存しないで数える

休み券を使った日には、記録がありません。ない記録から使ったことは読めないので、別に保存するしかない。題材を決めたときは、そう考えていました。けれども配り方にも使い方にも、人の判断は入りません。最初の記録日から今日まで1日ずつたどれば、毎回同じ答えが出ます（開発者が了承）。

図1　記録日を1日ずつたどる

  1. 1記録のある日：連続日数を1増やす。7の倍数になったら休み券を1枚足す（2枚を超えない）。最長記録を更新する。
  2. 2記録のない日（今日より前）：休み券があれば1枚使い、連続日数はそのまま。なければ途切れる。
  3. 3今日：記録がなければ何もしない。今日が終わるまでは途切れていない。

たどった結果から、いまの連続日数、休み券の枚数、最長記録、最後に休み券を使った日、最後に途切れた日が出ます。後ろの2つは、次の節のカードと帯を出すかどうかに使います。この計算は画面から切り離してテストを書きます。日をまたぐ、2枚使う、途切れて0枚に戻る、どれも指で確かめるには日にちがかかりすぎるからです。

03 / display

いつ、何を見せるか

表2　画面上の帯（連続記録の帯）の出し方

状態大きな数下の一言
今日はもう叩いた30日連続今日の分はできた
今日まだ、続いている29日連続今日はまだ。1回で30日目
途切れたあと、まだ叩いていない「0日」は出さない今日の1回で1日目

その日最初の記録が閉じると、日数がめくれて1増えます。叩き切った記録ならフィナーレと同じ1打で、途中で閉じた記録なら控えめに。連続 7、30、100、365 日と、その先365日ごとが節目で、届いた1打で札を1枚積みます。1年を超えた人にも、年に1度は札が出ます。

途切れた直後は、やめる人が出る瞬間です。途切れたと示された人は続ける率が約66%から約58%に下がる、という研究もあります。だから「また1日目から」とだけ見せず、途切れても残るもの（最長記録と DT）を前に出します。

表3　1度だけ出すもの

場面出すもの出さないもの
途切れたあと、最初に開いたとき途切れたときのカード。「連続記録は29日で止まりました」、最長記録と DT を大きく、「ためた 987 ドパは、そのまま」。ボタンは「今日の1回から」「0日」の表示
休み券が使われたあと、最初に開いたとき上に2秒だけ帯。「休み券を1枚使って、29日連続をつなぎました」「昨日は休みましたね」のような責める文

どこまで見せたかは、端末の設定（UserDefaults）に小さく覚えておきます。記録とは別の、消えても困らない値です。消えたら、直近の途切れか休み券をもう1度見せるだけで済みます。

04 / screens

関連する画面

  • ホーム

    いちばん上が連続記録の帯。途切れたときのカードと休み券の帯もこの画面に重ねる。帯の左側を押すと今日の記録が開く。

    この機能の設定はない。休み券は自動で使われ、選べない。
