features/アプリの外

LP（公開ページ）

https://yat-tat-ta.web.app/（日本語）と /en/（英語）に置く、アプリの紹介のページ。初めて Yat Tat Ta を知った人が、App Store に進む前に「何をするアプリか」を見る場所で、リンクカードを押した人もここに着きます。見た人数と App Store のボタンを押した数を Google アナリティクスで数え、そこから先で入れたかはキャンペーンリンクで見ます。2026-10-09 に、サポートだけのページから作り替えました。

01 / why

サポートのページでは、なぜ足りなくなったのか

もとのページは、App Store Connect にサポート URL として出すためのものでした。問い合わせ先とプライバシーポリシーへのリンク、記録とアカウントの説明だけ。1.0 の公開まではそれで足りていました。

状況を変えたのはリンクカードです。LINE や X でカードを押した人は、このページに着く。カードで日数とマスを見て興味を持った人に、問い合わせ先だけを見せても、App Store には進んでもらえません。そこで、審査の結果を待つあいだに、スクリーンショットと30秒の動画で「見ているだけで楽しい」ページに作り替えることになりました（開発者の注文、2026-10-09）。参考に挙がった Pinterest と Dribbble の LP のまとめは、どちらもこちらからは開けなかったので、アプリの LP でよくある型（大きな見出しと動画、使い方の3歩、スクリーンショットの横流し、機能、もう一度ボタン、よくある質問）で組みました。

あわせて、見た人がどれだけ App Store まで進んだかを測りたい、という注文もありました。これまでの公開ページは「外のフォントも読み込まない。開いた人の情報を、ほかのサービスへ送らない」方針でしたが、開発者の判断で Google アナリティクスを入れ、この方針を変えています（2026-10-09）。

02 / layout

上から順に

  1. 1. 上の帯：ロゴ、言語の切り替え、小さな App Store のバッジ。スクロールしても上に残る。
  2. 2. 冒頭：「食べて、しゃがんで、連続タップ。」（英語は「Eat. Squat. Tap.」）、掲載情報のプロモーション用テキスト、App Store のバッジ、「買い切り。広告なし、アプリ内課金なし。ログインもいりません。」。右に30秒の動画を傾けた枠で置き、後ろで放射の光が回り、「1回＝1打」の丸いシールが揺れる。下をスクワットマンが行進する。
  3. 3. 3歩：食べる、しゃがむ、連続タップ。
  4. 4. スクリーンショット：App Store と同じ6枚を、横にスクロールで流す。
  5. 5. 機能：演出（CHANCE、激熱!!、FEVER、筋肉確定）、連続記録と休み券、ドパ、今日の記録カード、ログインなしで始められること、今日まだ通知。
  6. 6. もう一度ボタン：黒地に「スクワット、終わった？」と App Store のバッジ。
  7. 7. よくある質問：料金、ログイン、機種変更、回数、電波、対応機種の6つ。
  8. 8. サポート：問い合わせ、プライバシーポリシー、記録とアカウント。フッターに Google アナリティクスで数えていることの一言。

見た目はアプリと同じ紙の地、太い黒の枠、ずらした影。書体は Google Fonts の Dela Gothic One（見出し）と M PLUS Rounded 1c（本文）。見出しは1行ずつ落ちてきて、下の節はスクロールで下から出てくる。動きを減らす設定の人には、動きを全部止めて最初から見せる。

03 / rules

決まりごと

表1　LP の決まり

項目決まり理由
サポート URL を兼ねるいちばん下に、問い合わせ、プライバシーポリシー、記録とアカウントの欄を残すApp Store Connect のサポート URL がこのページ。Apple はサポート URL に問い合わせ先を求める。審査中の版ではサポート URL を変えられない
App Store のボタンApple の公式のバッジ（日本語版と英語版）を、形も色も変えずに置く。バッジのファイルはページに同梱するApple のロゴを使った自作のボタンは、App Store のマーケティングのガイドラインで認められない。表示のたびに Apple から読むと、見た人の情報が Apple にも送られる
見た人数とボタンGoogle アナリティクス 4 で、ページを見た数（page_view）、App Store のボタンを押した数（app_store_click、置いた場所 bar、hero、cta ごと）、動画の音を出した数（video_sound_on）を数える。app_store_click をキーイベントにする開発者が決定（2026-10-09）。LP から App Store へ進んだ割合を見るため
入れたかApp Store へのリンクをキャンペーンリンクにする（ct は lp_言語_置いた場所）。App Store Connect の App 分析で見るGoogle アナリティクスは App Store のボタンを押したところまでしか見えない
リンクカードから来た人リンクカードから LP へ移すとき、URL に utm_source=share_card を付けるGoogle アナリティクスで、利用者の投稿から来た人を見分けるため
同意と Cookie欧州経済領域、英国、スイスから開いた人には Cookie を使わせない（同意モードで analytics_storage を断る）。ほかの地域は使う。広告の機能（Google シグナル、広告のパーソナライズ）は切る欧州では Cookie に同意が要る。同意の画面を出さずに済ませるため、その地域では Cookie を使わない
外部に送る情報の公表プライバシーポリシーの「公開ページで外部に送られる情報」に、Google アナリティクスと Google Fonts の送り先、送る情報、目的、止め方を書く。プライバシーポリシーのページ自体は外部を読み込まない電気通信事業法の外部送信規律。アプリそのものは今も分析に使わないことも書き分ける
書かないこと体への効果、パチンコやくじの語。文言は掲載情報のプロモーション用テキストとスクリーンショットをそのまま使う掲載情報と SNS の決まり事の1と2にそろえる
動画LP 用の30秒を日本語と英語で作る。叩き切ったあとの共有の誘いまで見せる。音なしで、見えている間だけ流し、「音を出す」で頭から音付きで流す開発者が決定（2026-10-09）。SNS の縦動画は叩き切ったところで終わり、共有の場面がない
