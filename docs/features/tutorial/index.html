features/はじめる

チュートリアル

はじめての幕が消えたあと、記録がまだ1件もない人に1度だけ、使い方を自分の指でやってもらう約1分の案内。ホームに暗い幕をかけて1か所ずつ照らし、スクワットマンを起こす、記録にならない練習連打を10回、帯、今日の記録カードの見本、DPW と DT のカード、歯車の順に回る。まだ Apple でログインしていない人には、最後に記録を残す場面を挟む。設定シートから何度でも見直せる。2026-10-07 設計、2026-10-08 に記録を残す場面、2026-10-09 に記録を貼る場面を追加。

表2　出すときと抜けるとき

項目決まり理由
出すときスプラッシュが消えた直後。端末の設定 tutorialShown が false で、記録が1件もないとき幕を見た人がそのまま続けて触れる。記録がある人は使い方を知っている
見せたことにする「はじめる」を押したとき、スキップして終えたとき途中で終了されたら、次の起動で場面1から出し直したい
スキップ吹き出しの右上に、場面1〜7でいつも出す。まだ Apple でログインしていない人は、押すと場面8へ飛び（練習の途中なら捨てる）、そこで「あとで」ならそのまま終わる急いでいる人を1分待たせない。ただ、機種を替えた人ほど使い方を知っていてスキップするので、記録を戻す場面だけは飛ばさない
進み具合の点場面1〜7の7つ。記録を残すとおわりは数えない記録を残すは出さない人がいるので、数えると人によって点の数が変わる
アプリを離れた練習の途中なら練習を捨て、いまの場面の頭に戻す練習は記録がないので、捨てても失うものがない
見直す設定シートの一番下の「使い方をもう一度」。シートを閉じて場面1から練習は記録を動かさないので、記録のある人が何度やってもよい
照らした場所場面4、6、7では押しても開かない。どこを叩いても次へシートが開くと、閉じるまで案内が止まる
教えないことフィーバータイム。今日まだ通知（初めて叩き切ったあとに、いまどおり問いかける）フィーバーは、いつ来るか分からないこと自体が中身
ひかえめモード照らす枠の移動と点滅、吹き出しの浮き上がりを止める。練習連打は本番と同じ扱いひかえめモードの考え方

記録を残す場面は、なぜ全員に出すのか

2026-10-08 に、最初の起動でログインを求めない作りへ変えました（アカウント）。それから、新しい iPhone に替えた人は匿名アカウントで、記録のない空のホームから始まります。Apple でログインすれば記録は戻るのに、そのことは設定シートの中にしか書いてありませんでした。

機種を替えた人だけに出せれば、それがいちばん静かです。けれど、前の iPhone で使っていた人を見分ける手は、いまのアプリにはありません。開発者の決定は「全員に出しますが、1行ではなくチュートリアルとして丁寧に出してください。」でした（2026-10-08）。初めての人にとっても、いずれ機種を替えたときの話として無駄にはなりません。

出す位置は、歯車のあとです。使い方を一通り触ってからなので、ログインの話が最初に来ません。練習連打は記録を作らないので、この場面で Apple ID のほうへ切り替えても、捨てる記録はふつう1件もありません。前の記録のある Apple ID で続けると、アカウントごと替わってチュートリアルは消え、戻ってきた記録の入ったホームになります。

文面では、ログインしなくても全部使えることを、ログインの得と同じ重さで書きます。「あとで」も「はじめる」と同じ金色の大きいボタンです。ログインを求める画面に見えると、App Store の審査（ガイドライン 5.1.1(v)）でまた断られるかもしれないからです。

表3　練習連打が本番と違うところ

項目練習連打
回数いつも10回。CHANCE 3打目、激熱 6打目、PUSH 8打目
記録作らない。DT、DPW、連続記録、今日の記録は動かない。「+N ドパ」も出さない

文字スクワットマンの上は「練習 残り」。フィナーレは本番と同じ2段で、確定は「筋肉確定」と「やったった！ 練習 10回」、ねぎらいは「あんたはえらい！」。言葉は回さない

記録の保存の形は変わりません。端末の設定に tutorialShown を1つ足すだけです。記録を残す場面を出すかは、端末にもサーバーにも残さず、起動のたびにいまのアカウントが匿名かどうかで決めます。
