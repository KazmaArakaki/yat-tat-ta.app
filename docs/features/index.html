features

機能一覧

Yat Tat Ta の機能は6つです。どれも同じ記録を読み書きします。記録を作るのは完了連打だけ、消すのは今日の記録だけで、ほかの4つは記録から数や形を計算して見せます。設計の経緯は 本作りの設計（2026-10-06）。

はじめる

  • account

    アカウント

    最初の起動は匿名アカウントで、ログインなしで叩ける。設定から Apple でログインすると、記録がアカウントに残り、機種を替えても戻る。2026-10-07 設計、2026-10-08 改訂。

記録する

  • done-mash

    完了連打

    スクワットのあと、その回数だけボタンを叩く。1打でスクワット1回が1ドパに変わる。最後の1打でフィナーレ。

ふり返って続ける

  • dopa-totals

    ドパの合計

    DT（これまでの全部）と DPW（直近7日間）。DPW は前の7日と自己ベストに、DT は次の節目に並べる。

  • streak

    連続記録と休み券

    何日続いたか。7日ごとに休み券が1枚。途切れたときは最長記録と DT を前に出す。

  • today-records

    今日の記録

    連続記録の帯から開く。今日の記録を並べ、間違えてできた1件を左へスワイプして消す。

  • share-card

    今日の記録カード

    今日の記録のシートから、連続日数と7日のマス目を1枚の画像にして共有シートに渡す。画像は端末の中で作る。

  • history

    履歴

    DPW と DT のカードから開く。縦に時刻、横に日付を取り、記録1件を人形1つで置く。背景に日ごとのドパと7日移動平均。

  • splash

    スプラッシュ

    起動したときとその日最初に開いたとき、続けた日を人形の隊列で並べ、空いた今日の席を見せる。1.65秒で、数だけが連続記録の帯へ飛ぶ。

  • tutorial

    チュートリアル

    はじめての幕のあと約1分。スクワットマンを起こし、記録にならない練習連打を10回叩いて、帯とカードと歯車を照らして回る。設定から見直せる。

知らせる

  • today-reminder

    今日まだ通知

    まだ叩いていない夜に1回だけ。開かれなければ7日で自分から止まる。
