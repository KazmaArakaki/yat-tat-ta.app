今日叩いた記録を並べ、間違えてできた1件を消す。消したあとの数は、残った記録から計算し直します。2026-10-06 決定。

01 / rules

決まりごと

表1　開き方と消し方

項目決まり理由
開く連続記録の帯の左側（日数と下の一言）を押す。下からシートが出るホームに部品を足さない。「今日のぶんは済み」から今日の中身へつながる。
並ぶもの今日（記録日、午前4時区切り）の記録。新しい順。時刻、回数、フィーバーのドパ消したくなる間違いは、どれもその日のうちに気づく。
消す左へスワイプして「消す」。確かめの問いは挟まない。元に戻す手段はないスワイプと押すことで2手。間違えて消しても、叩き直せば同じ日の記録になる。
消せない昨日より前の記録。叩いている最中の連打過去を消すと、休み券が使われ直し、連続記録が過去にさかのぼって途切れることがある。
消したあと連続記録、休み券、DT、DPWを計算し直す。今日まだ通知を予約し直す。演出は出さないどれも保存せず記録から計算しているので、記録1件を消せば揃う。
共有左上の共有のボタンを押すと、「LINEで共有する」「Xで共有する」「他の方法で共有する」のメニューが出る。LINE と X には今日の記録カードのリンクカードの URL を、他の方法では縦長の画像を共有シートに渡す。1度も叩いていない人には出さない（2026-10-09）。共有シートで送り終えたら、または LINE か X の投稿画面を開けたら、その日は「共有した」として、もう共有の誘いを出さない叩き終えて落ち着いてから開く場所なので、演出の邪魔をしない。詳しくは今日の記録カード。

届いた節目の札は、出したまま取り消しません。DT や連続記録が戻るので、次にまたいだときにもう一度出ます。
