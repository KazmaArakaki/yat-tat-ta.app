ロゴを作る

開発者の注文

ロゴを作りたい。

01 / question

ロゴがいちばん見られる場所

前のセッションで、スプラッシュからロゴを外しました。起動の一瞬は、続けた日の隊列に使う。ロゴを見てしゃがむ人はいないからです。

では、ロゴはどこに出るのか。毎食後にこのアプリを開く人は、1日3回、ホーム画面のアイコンを押します。押す前の0.5秒、指が探すのはそのアイコンです。ところが今、そこにあるのは iOS が出す白い板でした。project.yml の ASSETCATALOG_COMPILER_APPICON_NAME は空のままです。

だから今回作るロゴは2つです。

  1. 01 マーク ＝ アプリアイコン

    ホーム画面、設定、通知、App Store に出る絵。60pt で毎日見られ、通知の横では 20pt まで縮む。今回の本題。

  2. 02 ワードマーク ＝ 名前の文字組み

    「Yat Tat Ta」の書き方。スプラッシュでもう使っている形を、正式なものにする。

02 / candidates

マークの3案

アプリの中で、いちばんこのアプリらしいものは何か。答えは2つに割れました。叩くとしゃがむスクワット隊の人形と、3拍で落ちる名前です。人形を1人で描くか、3人で描くか、名前で描くか。3案はその3通りです。

人形は、アプリで描いている点（SquatterLayer の立つ姿としゃがむ姿）をそのまま使いました。アイコンの人形とアプリの人形は、同じ人です。

A しゃがむ1人

採用

金の地に、dopa の人形がしゃがんでいる。足元に輪。

  • ＋ 29pt でも人形と分かる。線が太く、形が1つしかない
  • ＋ 金は「押せるもの」の色。アイコン自体が叩く的になる
  • － 名前の3拍は入らない

B 3拍

立つ、半分、しゃがむ。3人で Yat、Tat、Ta。最後の1人だけ dopa。

  • ＋ 名前の拍とスクワットの動きが1枚に入る
  • － 60pt で1人あたり15pt。29pt では棒の束に見える
  • － 地が paper。白い壁紙の上で輪郭が消える

C 名前を積む

Yat、Tat、Ta を3段に。Ta だけ dopa で、着地でつぶれた形。

  • ＋ 名前をそのまま覚えてもらえる
  • － アイコンの下にも名前が出る。同じ文字が2回並ぶ
  • － スクワットのアプリだと、絵からは分からない

03 / home screen

ほかのアプリと並べる

アイコン1つを大きく見ると、どの案もそれなりに見えます。困るのは、ほかのアプリの中に置いたときです。灰色の板は、ほかのアプリの代わり。指で探すつもりで見比べてください。

左が明るい壁紙と明るいアイコン、右が暗い壁紙と暗いアイコン。上の段から A、B、C。

04 / appearance

A を3通りの見た目で

iOS 26 からは、使う人がアイコンの見た目を選べます。明るい、暗い、色付き、クリア。アイコンを1枚しか渡さないと、暗いと色付きは iOS が勝手に作ります。金の地を勝手に暗くされると、人形まで沈む。だから、暗いと色付きは自分で描きます。

クリアは、明るい版から iOS が作ります。輪郭が人形1人しかないので、ガラス越しでも形が崩れません。

05 / wordmark

ワードマークは、もうある

名前の書き方は、スプラッシュで決まっていました。丸ゴシックの Black、3語を空けて並べ、Ta だけ dopa。3拍めで隊列の波が今日の席に届く、あの Ta です。新しく作る理由は見当たりません。これを正式なワードマークにします。

Yat Tat Ta

Yat Tat Ta

アプリでは SF Pro Rounded の Black（Wordmark）。この見本では M PLUS Rounded 1c で代えている。マークと並べるときは、マークの高さを文字の高さの1.4倍にする。

06 / implementation

決まったら作るもの

案が決まってからの作業です。データの保存の形は変わりません。

  1. 1. 元の絵を SVG で置く（ios/Design/AppIcon/ に明るい、暗い、色付きの3枚）
    人形の点がアプリと同じだと確かめられる形で残すため。PNG だけだと、人形を直したときに描き直せない。
  2. 2. Icon Composer で AppIcon.icon を作る（地、輪、人形の3層）
    iOS 26 のガラスの見た目は、層が分かれていないと付かない。人形だけが浮き、地は奥に残る。
  3. 3. project.yml の ASSETCATALOG_COMPILER_APPICON_NAME を AppIcon にする
    いまは空にして、XcodeGen の既定を外している。これを戻さないとアイコンが入らない。
  4. 4. ロゴの見本ページ ui/components/logo/ を作る
    App Store の画面やドメイン yat-tat-ta.com でロゴを使うとき、色と並べ方をここで引く。
  5. 5. 開発者が実機のホーム画面で、3通りの見た目を確かめる
    シミュレーターではガラスの見え方が実機と違う。

07 / decisions

決めること

  • 決定　マークは A「しゃがむ1人」（開発者が決定、2026-10-07）。
  • 決定　ワードマークはスプラッシュの「Yat Tat Ta」（Ta だけ dopa）を正式にする。
  • 決定　アイコンは明るい、暗い、色付きを自分で描く。クリアは iOS に任せる。
  • 決定　ロゴの色は、アプリの色の決まり（UI の基本方針）の外に置かない。新しい色は足さない。
