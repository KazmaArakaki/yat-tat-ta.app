2026-10-06 18:29 / 設計セッション 状態：developing

多言語展開の進め方を決める

結果（レビュー済み）

日本語と英語で、同時に。

画面の文言、通知、ストアの説明文を英語にする。
声も英語で作り直し、「激熱」のようなパチンコの言葉も英語に置き換える。
日本語と英語以外の端末には、英語で出す。

3つとも開発者が決定。訳語と声の台本は devops／多言語の決まり事。

01 / position

残っていたのは、どの言語で出すか

文言の持ち方は、本作りのときに決めてあります。開発言語は日本語で、画面の文言は String Catalog に集める。おかげで、訳す対象はいま80件ほどの文言にまとまっています。残っていたのは、どの言語で出すかと、ストアの説明文でした。

開発者は日本語と英語で同時に出すことにしました。機能は増えません。5つの機能はどれも、同じふるまいのまま英語で話すようになります。

02 / flavor

「激熱」は、英語で何と叫ぶのか

このアプリの味は、パチンコの実況にあります。日本語の声のまま残し、画面の文字もローマ字にすれば、その味は手つかずで残る。作り直す手間もいりません。

開発者が選んだのは逆でした。声も文字も英語にする。英語で遊ぶ人に「GEKIATSU」は意味を持たず、ただの記号として流れていきます。演出の言葉は、意味が分かって初めて、上がっていく感じが伝わるということです。

置き換えるときは、勢いを残すことを優先しました。激熱は RED HOT!!、〇〇確定は「MUSCLE／LOCKED IN」の2行、ドパ突破は DOPA BREAK!。フィーバーの「叩き放題」は ALL YOU CAN TAP にして、食べ放題（all you can eat）にかけています。食後のアプリなので。全部の対応は訳語表に置きました。

03 / fallback

フランス語の iPhone には、何語で出るか

何もしなければ、日本語で出ます。端末の言語がアプリの持つ言語のどれとも合わないとき、iOS はアプリの「開発の言語」を使うからです。このアプリの開発の言語は日本語です。

日本語と英語以外の人には、英語のほうが読めるはずです。そこで、アプリの開発の言語（Info.plist の CFBundleDevelopmentRegion）だけを英語にします。String Catalog の元の言語は日本語のままで、文言は日本語で書き続けます。この組み合わせで本当に英語に落ちるかは、実装のあとにフランス語のシミュレーターで確かめます。

04 / store

英語のストアに、研究の1文を入れるか

入れません。日本語のストアには「食後に少し体を動かすと、血糖値の上がり方がゆるやかになる、という研究があります」を入れると決めました。英語のストアはアメリカやイギリスなど多くの国に並びます。健康の広告の決まりを、その国ごとには確かめていません。健康効果の書き方で決めたとおり、確かめられない国では注意書きだけを残します。英語の説明文と注意書きの案はdevopsに置きました。

05 / implementation

実装でやること

Claude の作業は3時間ほど。開発者の作業は、英語の声22本を作る30〜45分と、実機での確認10分。

  1. 1
    英語をアプリの言語に足す（project.yml、Info.plist）。英語の端末で英語を出し、それ以外の端末でも英語に落とすため。
  2. 2
    String Catalog の全文言に英語を入れる。訳語表に合わせる。通知の文言も含む。
  3. 3
    訳せない形の文言を直す。「FEVER 終了」はコードに直接書かれているので、String Catalog に移す。声のファイルがないときの読み上げも、端末の言語で読むようにする。
  4. 4
    大きな文字を、画面の幅に収める（MetalText と、その大きさを決めているところ）。いまは文字数で大きさを決めていて、2文字の「筋肉」と6文字の「MUSCLE」では幅がまるで違うため。
  5. 5
    声のファイルを言語ごとのフォルダに分ける（Sounds/ja.lproj/、Sounds/en.lproj/）。ファイル名は同じにし、iOS に選ばせる。効果音とループ曲は言葉がないので分けない。
  6. 6
    英語の声22本を作る（開発者）。声の台本を使い、日本語と同じ声の役で。届くまでは英語の読み上げで代わる。
  7. 7
    英語で画面を確かめる。シミュレーターで見本の演出を全部出して撮る（Claude）。フランス語の端末で英語に落ちるかも見る。

保存の形は変えない。

06 / decisions

決めたこと（2026-10-06 開発者がレビュー）

  1. 01日本語と英語で同時に出す（開発者が決定）。
  2. 02声は言語ごとに作る（開発者が決定）。
  3. 03パチンコの言葉は英語に訳す（開発者が決定）。訳語は訳語表に従う。
  4. 04日本語と英語以外の端末には英語で出す。
  5. 05英語のストアには研究の1文を入れず、注意書きだけを残す。
  6. 06文言を足したら、同じ変更で英語も入れる。
