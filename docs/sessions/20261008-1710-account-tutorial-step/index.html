01 / why

新しい iPhone で、記録が消えたように見える

前のセッションログインせずに始めるで、最初の起動はログイン画面を通らなくなりました。Apple でログインしていた人が新しい iPhone に替えると、匿名アカウントで空のホームから始まります。Apple でログインすれば記録は戻るのに、それを知る場所は設定シートの中にしかありません（課題 guest-restore-hint）。

気づくのが遅いほど損もします。匿名のまま叩いた記録は、Apple のアカウントへ切り替えるときに捨てる決まりだからです。

前の iPhone で使っていた人だけを見分けて知らせる手も考えました。iCloud の key-value storage に「Apple でログインしたことがある」という印を置けば、同じ Apple ID の新しい iPhone で読めます。それでも開発者は、全員に、チュートリアルの1場面として丁寧に出すほうを選びました（開発者が決定、2026-10-08）。iCloud を使っていない人にも届き、新しい権限も要りません。

02 / decisions

決めたこと

  • 決定　機種変更で記録が戻ることは、全員に、チュートリアルの1場面として伝える。1行の注意書きにはしない（開発者が決定、2026-10-08）。
  • 提案　場面の名前は「記録を残す」。歯車（回数を変える）のあと、おわりの前に置く。歯車の場面で設定シートの場所を見せた直後なので、「あとからでも歯車から」が通じる。
  • 提案　まだ Apple でログインしていない人にだけ出す。ログイン中の人が「使い方をもう一度」で見直すときは飛ばす。
  • 提案　「スキップ」を押しても、この場面だけは出す。機種を替えた人ほど使い方を知っていて、スキップを押すはずだから。スキップで来たときの「あとで」は、おわりを挟まずにそのまま閉じる。
  • 提案　ボタンは「Appleで続ける」と「あとで」の2つ。「ログインしなくても、このまま全部使えます」を同じカードに書き、ログインを求める画面に見せない（ガイドライン 5.1.1(v)）。

  13. 記録を残すまだログインしていない人だけ。新しい場面

  15. おわり

機種を替えた人がここで「Appleで続ける」を押すと、その Apple ID にはもう前のアカウントがあるので、引き継ぎではなく切り替えになります。捨てる記録はありません。練習連打は記録を作らないので、匿名の記録はまだ0件です。確かめの画面も出さずに切り替わり、ホームが前の記録で作り直されます。記録のある人にはチュートリアルを出さない決まりなので、続きは出ません。

初めて Apple を使う人なら、引き継ぎがそのまま済み、おわりの場面へ進みます。

04 / card

記録を残す場面のカード

記録を残す

Apple でログインすると、記録がアカウントに残ります。iPhone を替えても、同じ Apple ID でログインすれば戻ります。

前の iPhone で Apple でログインしていた人は、ここで続けると、これまでの記録が戻ります。

ログインしなくても、このまま全部使えます。あとからでも、歯車の設定からできます。

Appleで続ける
あとで

名前とメールアドレスは受け取りません。

  • 照らす場所はない：おわりの場面と同じく、幕の真ん中にカードを置く。幕を叩いても進まない。どちらかのボタンを選んでもらう。
  • 太字の1文：機種を替えた人に向けた文。読み飛ばされないよう、この1文だけ太くした。
  • 「あとで」：ほかの場面の「はじめる」と同じ金色のボタン。Apple のボタンと同じ大きさにして、どちらも選べることを形で示す。
  • つながらないとき：カードの中に「つながりませんでした」を出す。匿名で叩いた記録がある人（見直しのとき）が、記録のある Apple ID で続けると、切り替えの確かめが出る。

05 / implementation

作ったもの

記録の形も置き場所も変えていません。

  1. 1. TutorialStep に .account を足す。照らす場所なし、叩いても進まない、進み具合の点には数えない
    出さない人がいる場面なので、点に数えると人によって点の数が変わる。
  2. 2. AppModel：offersAccount、skipTutorial、leaveAccountStep
    出すかどうかと、スキップしても出す決まりを、画面ではなくモデルに置いてテストできるようにするため。
  3. 3. Account：作った AppModel に、匿名アカウントかどうかを渡す。引き継げたら外す
    ログイン中の人が見直すときに、この場面を飛ばすため。
  4. 4. TutorialOverlay：記録を残すカード。吹き出しの「スキップ」を skipTutorial につなぐ
    Apple のボタン、失敗の一言、切り替えの確かめは、設定シートと同じ Account の処理を使う。
  5. 5. テストを4つ足す。文言を日本語と英語で6件足す
    出る人と出ない人、スキップしたとき、場面の中でのスキップ。テストは全部で91件、すべて通った。

06 / developer

開発者にお願いすること

カードの見た目と Apple のボタンは、実機でしか確かめられません。アプリを消して入れ直すと、匿名アカウントで始まり、チュートリアルが流れます（デバッグトークンの登録し直しを忘れずに）。

  1. 1　約3分

    チュートリアルを最後まで進め、歯車のあとに記録を残すカードが出ること、「あとで」でおわりへ進むことを見る。

  2. 2　約3分

    入れ直して、最初の場面で「スキップ」。記録を残すカードが出て、「あとで」で閉じることを見る。

  3. 3　約3分

    入れ直して、カードで「Appleで続ける」。前の記録が戻り、チュートリアルが消えることを見る。
