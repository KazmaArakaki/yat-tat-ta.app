今日の記録から取り消す

このセッションで作るもの（レビュー済み）

日数を押すと、今日の記録

連続記録の帯の左側（日数と、その下の一言）を押すと、下から「今日の記録」のシートが出る。
並ぶのは今日（午前4時区切り）の記録だけ。1件を左へスワイプして「消す」を押すと消える。
連続記録、休み券、DT、DPW は、残った記録から計算し直す。

01 / position

ホーム1枚のまま、記録を見せる場所を作る

本作りでは、取り消しを作らないと決めました。取り消しがなければ記録を一覧で見せる理由もなく、画面はホーム1枚で済む。その判断は、裏返せばこう読めます。取り消しを作るなら、記録を見せる場所が要る。

場所は、開発者が「今日のぶんは済み」の一言から開くほうを選びました。あわせて「n日連続」の日数からも開けるようにします。帯の左側をまるごと1つのボタンにするので、ホームに部品は増えません。今日の記録が1件もない日に押しても、空のシートが出るだけです。

機能としては5つめの今日の記録になります。記録を作るのは完了連打だけで、消すのはこの機能だけ。ほかの3つ（ドパの合計、連続記録と休み券、今日まだ通知）は、残った記録を読み直すだけで、作りを変えません。

02 / today only

昨日の記録も消せたほうがいいのか

消したくなる場面は2つありました。ポケットの中で画面に触れて、しゃがんでいないのに数打が入り、60秒後に1件として閉じる。フィナーレのあと勢いで叩き、1件多くなる。どちらも、その日のうちに気づく間違いです。

昨日より前を消せるようにすると、話が変わります。記録のない日が過去に生まれ、休み券が使われ直し、連続記録が過去にさかのぼって途切れることがある。途切れたときのカードを、自分で消した記録のせいで見ることになります。今日の記録なら、それは起きません。今日はまだ終わっていないので、今日の記録をすべて消しても「今日はまだ」に戻るだけです。

消せるのは今日の分だけにする。

03 / effects

1件消すと、何が戻るか

休み券も連続記録も保存していないので、消すのは記録1件だけです。残りは、起動したときと同じ計算をやり直すと、自然に戻ります。

消した記録戻るもの
今日の記録のうち1件DT と DPW から、その記録のドパ（フィーバーの分も）が引かれる
今日の最後の1件連続記録の帯が「今日はまだ。1回で30日目」に戻る。今日で7の倍数に届いて増えた休み券も消える
節目に届いた記録札は出したまま取り消さない。DT や連続記録が戻るので、次にまたいだときにもう一度出る
今日まだ通知今日の記録がなくなったら、今夜の通知を予約し直す

消したときに演出は出しません。ドパが減るのを大げさに見せると、消すことが罰のように見えるからです。帯とカードの数が、静かに戻ります。

04 / confirm

「本当に消しますか」を挟むか

挟みません。左へスワイプして、出てきた「消す」を押す。それだけで2つの手順を踏んでいて、うっかりでは起きにくい。iPhone の「メール」や「メモ」も同じ形です。消したあとに元へ戻す手段は作りません。消すのは今日の記録だけなので、間違えて消しても、叩き直せば同じ日の記録になります。

叩いている最中は、帯を押せないようにします。開いている連打は、まだ記録になっていないからです。閉じてから並びます。

05 / mock

修正イメージ

左：帯の左側が押せるようになる（見た目は「›」が付くだけ）。右：今日の記録のシート。2件目を左へスワイプしたところ。動く見本は ui／今日の記録。

今日の記録がないときは、帯の一言は今のまま（「今日はまだ。1回で30日目」）で、「›」も付けない。押せばシートは出て、「今日の記録はまだありません。叩くと、ここに1件ずつ並びます。」と出す。

06 / implementation

実装でやること

所要はあわせて2時間ほど。

  1. 1
    今日の記録を読む（AppModel.todayRecords）。いまの記録日の記録を、新しい順に返す。シートに並べるため。
  2. 2
    1件消す（AppModel.delete(_:)）。今日の記録でなければ、叩いている最中なら、何もしない。消したら保存し、記録を読み直して Ledger を作り直し、今日まだ通知を予約し直す。昨日より前を消させないことと、計算のし直しを1か所にまとめるため。テストで、最後の1件を消すと「今日はまだ」に戻り、7日目の休み券も消えることを確かめる。
  3. 3
    今日の記録のシート（新規 Records/TodayRecordsView.swift）。List にスワイプの「消す」を付ける。VoiceOver では、行の操作から消せる。
  4. 4
    帯の左側をボタンにする（StreakBar、HomeView）。今日の記録があれば一言に回数と「›」を足す。叩いている最中は押せない。

保存の形（SquatRecord の欄）は変えない。消すのは、開発者が「消す」を押した今日の記録1件だけ。

実装 2026-10-06

作ったもの

  • AppModel：今日の記録（todayRecords）を、記録を読み直すたび、閉じるたび、日をまたぐたびに作り直す。delete(_:) は今日の記録で、叩いている最中でなければ消し、読み直して今日まだ通知を予約し直す
  • Records/TodayRecordsView.swift：今日の記録のシート。スワイプしきっても消えない（「消す」を押して初めて消える）
  • StreakBar、HomeView：帯の左側をボタンにし、今日の記録があれば一言に回数と「›」を足す

テスト45件（うち今日の記録6件）が通った。最後の1件を消すと「今日はまだ」に戻ること、7日目の記録を消すと休み券も消えること、昨日の記録と叩いている最中は消せないことを確かめている。シミュレーターでシートの見た目を確かめた。実機でのスワイプはまだ。
