01 / gap

幕を見たあとに、分からないこと

最初の起動には、もうはじめての幕があります。14秒で、人形1人が「食べたら、しゃがんで、叩く」をやって見せる。何をするアプリかは、これで伝わるはずです。

ところが、幕が消えたあとのホームでは、スクワットマンが床に寝ています。叩いても何も起きません。0.5秒の長押しで起こす決まりは、ポケットの中で記録が始まらないための一段で、見ただけでは分からない。最初の食事のあと、20回しゃがんでから寝ているスクワットマンを叩き、反応がなくて閉じる。いちばん避けたい初日です。

帯を押すと今日の記録、カードを押すと履歴、歯車で回数。こちらは困るほどではないものの、自分で見つけるまで気付かない人がいそうです。幕は見せるだけで、触らせない。チュートリアルの仕事は、その残りを指でやってもらうことです。

02 / one minute

1分を7つに割る

幕とは別に、チュートリアルだけで約1分にします（開発者が決定、2026-10-07）。幕の14秒と合わせると、最初の起動は75秒ほど。長いかどうかは、叩いている時間の割合で決まると考えました。7つの場面のうち、手を動かすのは最初の2つで、その2つに17秒を使います。

  1. 1 起こす　5秒

    叩く場所を照らし、長押しでスクワットマンを起こしてもらう。起きたら次へ。

  2. 2 練習連打　12秒

    しゃがまずに10回叩く。CHANCE、激熱、PUSH、筋肉確定まで本番どおりに出る。

  3. 3 いまのは練習　8秒

    記録に残らないこと、本番は食べてしゃがんだあと、途中でやめても残ることを言う。

  4. 4 続けた日　9秒

    連続記録の帯を照らす。休み券と、押すと今日の記録が開くこと。

  5. 5 ためたドパ　9秒

    DPW と DT のカードを照らす。1回1ドパと、押すと履歴。

  6. 6 回数を変える　6秒

    歯車を照らす。目標回数はいま20回、5〜100回で変えられる。

  7. 7 おわり　5秒

    「食べたら、しゃがんで、叩く。」と「はじめる」。押すとホームだけが残る。

  8. 合計　約54秒

    読む速さで前後する。スキップはいつでも押せる。

教えないものもあります。フィーバータイムは、いつ来るか分からないこと自体が中身なので、先に言いません。今日まだ通知も、いまどおり初めて叩き切ったあとに問いかけます。

03 / practice

しゃがんでいない10回の行き先

練習で叩いた10回を、最初の記録にしてしまう手もありました。インストールしたその場で1日目がつく。気持ちのいい始まりになったはずです。

それでも記録にはしません（開発者が決定、2026-10-07）。1ドパはスクワット1回、というのが完了連打の前提で、アプリはしゃがんだかを確かめない代わりに、叩く人を信じています。チュートリアルの側から「しゃがまずに叩いて」と頼んでおいて、その10回を数えるわけにはいかない。この叩き方を練習連打と呼びます。

表1　練習連打と本番の違い
項目練習連打理由
回数いつも10回。目標回数によらない10回で CHANCE（3打目）、激熱（6打目）、PUSH（8打目）を全部通る。20回だと場面2だけで20秒を超える
記録作らない。DT、DPW、連続記録、今日の記録は動かないスクワットをしていない1打を混ぜない
スクワットマンの上の文字「練習 残り」本番の「スクワット 残り」と見分ける
「+N ドパ」出さない。飛ぶドパの粒と文字は出す増えたように見せると、カードの 0 と食い違う
フィーバーのくじ引かない練習で当たると、本番の驚きを先に使ってしまう
節目、ドパ突破、虹の先バレ出さないどれも記録の数から決まる。練習は数を動かさない
フィナーレ本番と同じ2段。確定は「筋肉確定」で、下の「+N ドパ」の代わりに「練習 10回」。ねぎらいは「あんたはえらい！」。言葉は回さない。長さは本番と同じく声の長さで決まる（約3秒）本番のごほうびを1度見せておく。言葉を回すと、本番の1回目が2番目の言葉から始まってしまう
今日まだ通知の問いかけ出さない問いかけは「初めて叩き切ったあと」。練習は数えない
60秒止まったとき閉じない。案内を出したまま待つ記録がないので、閉じても残すものがない
終わったあとのスクワットマン倒れ込んで寝る本番でも叩き切ったら寝る。最初の本番も起こすところから

04 / when

誰に、いつ出すか

表2　出すときと抜けるとき
項目決まり理由
出すときスプラッシュが消えた直後。まだ見せていなくて（tutorialShown が false）、記録が1件もないとき幕を見た人がそのまま続けて触れる。記録がある人は、もう使い方を知っている
見せたことにするとき「はじめる」を押したとき、スキップしたとき最後まで見た、か、いらないと言った。どちらも2度目はいらない
途中で離れたときアプリを離れたら、練習の途中なら練習を捨て、いまの場面の頭に戻す。終了されたら、次の起動で場面1から見せたことにしていないので、もう一度出してよい
見直す設定シートの一番下に「使い方をもう一度」。押すとシートを閉じて場面1から。記録のある人にも同じ練習連打友だちに見せたい、忘れた。練習は記録を動かさないので、何度やってもよい
出さないとき計測モード（-perf）、演出の確認用の起動引数があるときスプラッシュと同じ
重ね物途切れたときのカード、休み券の帯は、チュートリアルが終わってから記録が1件もない人には、どちらもまだ出ない。見直しのときだけ重なりうる
照らした場所場面4〜6で帯やカードや歯車を押しても開かない。どこを叩いても次へ進むシートが開くと、閉じるまで案内が止まる

06 / implementation

作るもの

SwiftData の記録の形は変わりません。端末の設定（UserDefaults）に、見せたかどうかの tutorialShown を1つ足すだけです。消えても、記録がある人には出ない。

  1. 1. TutorialStep（7つの場面）と、AppModel の tutorial、始める、進める、終える
    場面はホームの帯、叩く場所、カード、歯車をまたぐ。画面1枚の状態として AppModel に置けば、HomeView が重ね物を出すいまの形（スプラッシュやフィナーレ）にそろう。
  2. 2. MashSession に練習の印。AppModel.tap と close で、練習なら記録、くじ、節目、ドパ突破、問いかけを通らない
    叩く手触りと段階の演出は本番の道をそのまま使いたい。別の連打を作ると、演出を直すたびに2か所直すことになる。DT と DPW は練習の分を足さない。
  3. 3. SettingKey.tutorialShown と、スプラッシュが消えたときに出すかを決める処理
    はじめての幕は、出す瞬間に introShown を立てる。チュートリアルは途中で終了されたら出し直したいので、終えたときに立てる。
  4. 4. TutorialOverlay（暗い幕、照らす枠、吹き出し、スキップ）。帯、叩く場所、カード、歯車の位置は anchorPreference で受け取る
    照らす枠は、端末の大きさや文字の大きさで動く本物の位置に合わせる必要がある。いまのスプラッシュも帯の数字の位置を受け取って飛んでいる。
  5. 5. SquatStageView の「練習 残り」と、案内中は下の文字と「+N ドパ」を隠す。FinaleOverlay の「練習 10回」の札
    本番と練習を見分ける。練習のドパを増えたように見せない。
  6. 6. 設定シートの一番下に「使い方をもう一度」
    見直す入り口。注意書きの上に置く。設定シートの見本にも同じ行を足す。
  7. 7. 文言を日本語と英語で Localizable.xcstrings に足し、訳語表にチュートリアル（Tutorial）と練習（Practice）を足す
    多言語の決まり事で、文言を足すときは2言語同時。
  8. 8. テスト：練習で記録が増えない、くじを引かない、問いかけが出ない、出す条件、終えたときとスキップで tutorialShown が立つ
    練習が記録に漏れると、連続記録と DT が狂う。いちばん壊したくないところを押さえる。
  9. 9. 開発者が実機で、通しの時間と、長押しが伝わるかを確かめる
    約1分に収まるかは、読む速さと叩く速さ次第。シミュレーターでは長押しの手触りが分からない。

07 / decisions

決めたこと

  • 決定　チュートリアルは、はじめての幕とは別にし、単体で約1分（開発者が決定、2026-10-07）。
  • 決定　練習の連打は記録しない。DT、DPW、連続記録に入れず、フィーバーのくじも引かない（開発者が決定、2026-10-07）。
  • 提案　練習は10回。場面は7つ（起こす、練習連打、いまのは練習、続けた日、ためたドパ、回数を変える、おわり）。
  • 提案　フィーバータイムは教えない。設定シートから見直せる。

08 / build

作ったところ

  • 練習のフィナーレは、本番と同じ2段（確定とねぎらい）にした。確定の下の「+N ドパ」を「練習 10回」に替え、ねぎらいは「あんたはえらい！」に固定。設計では1段に縮める案だったが、本番のごほうびをそのまま1度見せるほうを取った。長さは声で決まり、約3秒。
  • 照らす場所の位置は onGeometryChange で画面全体の座標を測って渡す。穴は当たり判定からも抜いてあり、叩く場面ではそのまま下のスクワットマンに指が届く。叩く場所はもとから広いので、穴を広げずにそのまま照らす（広げるとカードにかかった）。
  • 文言20個を日本語と英語で足した。英語は訳語表に3行足した。
  • テストを10個足した（TutorialTests）。練習で記録が増えない、くじを引かない、問いかけが出ない、途中でスキップやアプリを離れたら練習を捨てる、記録がある人には出ない、など。全79個が通る。
  • シミュレーターで、7つの場面を起動引数（-demo tutorial、tutorial-mash ほか）で開き、照らす位置と吹き出しを日本語と英語で確かめた。長押しと連打の手触り、通しの時間はまだ。実機で確かめる。
