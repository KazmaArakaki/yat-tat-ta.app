02 / steps

進めた順

開発者の Mac で1手ずつ。半分以上は「もう済んでいた」の確認で終わりました。詰まったのは 5 と 6 の2か所です。

  1. 1

    Apple ID

    既にあった。

  2. 2

    Xcode を入れる

    初回起動でプラットフォームに iOS を選択。iOS 27.0 Simulator（約8GB）のダウンロードが始まるが、実機に入れるだけなら不要。待たずに進めた。

  3. 3

    Apple Accounts

    Settings → Apple Accounts でサインイン済み。Role: Admin、Provisioned Devices 6台、証明書 OK。

  4. 4

    iPhone をつなぐ

    「このコンピュータを信頼」は既に信頼済みで出ず。デベロッパモードも既にオン。xcrun devicectl list devices で State: connected。

  5. 5

    Mac の Claude Code と xcodebuild

    Claude Code は 2.1.289 が入っていた。Mac 側にもリポジトリが clone 済みで、コミット 73b376c で一致。

    詰まり：xcode-select -p が CommandLineTools を指していて、xcodebuild がエラー。

    sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcodebuild -version   # Xcode 27.0
  6. 6

    空アプリを作る

    File → New → Project に iOS タブはない。選択肢は App / Command Line Tool / Package。App を選ぶと入力画面なしで「Untitled Project / MyApp」が即できる（Mac と iPhone 両対応の SwiftUI）。Signing & Capabilities で Team を個人名義の Developer Team に。

    詰まり：実行先の iPhone が「Incompatible（OS version lower than…）」。

  7. 7

    ▶ で実行

    iPhone に「Hello, world!」。完了。

再現手順は iOS 開発環境の構築手順 にまとめています。

03 / incompatible

なぜ iPhone が弾かれたか

iPhone は iOS 26.6.1。Xcode 27 の新規プロジェクトは、Minimum Deployments（最小対応 iOS）が 27.0 で作られます。iPhone のほうが古いので、入れられません。

作成直後

最小対応 iOS 27.0

iOS 26.6.1 の iPhone は Incompatible。

変更後

最小対応 iOS 26.0

General → Minimum Deployments の iOS を下げた。実行先に出るようになった。

26.0 は動作確認のための暫定値です。本番アプリで何にするかは決めていません。

04 / paid team

無料の Personal Team ではなかった

前回の調査では、無料の Apple ID だと約7日ごとに入れ直しが要る、と見込んでいました。チーム表示が Developer Team だったので、個人名義で Apple Developer Program（有料）に登録済みと判断しました。

  • 7日で起動しなくなる制限：なし。
  • iPhone 側で開発元を「信頼」：不要だった。
