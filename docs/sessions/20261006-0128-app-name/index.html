02 / before subject

題材より先に決めた

前回のセッションでは、名前は題材と一緒に決めるつもりでした。ドリルを作るなら「ドパドリル」、電卓なら「ドパ電卓」。ドパ〇〇 の事例は、どれも元の道具の名前を背負っています。題材が決まらないうちは、名前も決めようがないはずでした。

ところが、名前の材料はもう手元にありました。開発者が取得したドメイン yat-tat-ta.com と、それを逆さにした Bundle Identifier com.yat-tat-ta です。アプリ名をこれにそろえれば、ドメイン、ID、ホーム画面、ストアがすべて一つの名前で通ります。

前回の想定

ドパ〇〇

道具の名前が入る。題材を変えると名前も変わる。

採用

Yat Tat Ta

道具ではなく、使ったあとの気分の名前。題材が何でも通る。

「やったった」は、何かをやり遂げたときの得意げなひとことです。ドパ〇〇が道具にかぶせる快感は、まさにこの瞬間を大きくしたものでした。ドリルでも電卓でも、終わったあとに出る声は同じです。

03 / romaji

ひらがなではなく、ローマ字で

日本語の名前なら「やったった」と書くのが素直です。それでもローマ字にしたのは、開発者が 多言語展開 を考えているからです。ひらがなは、日本語を読めない人には模様にしか見えません。

iOS では、アプリ名も言語ごとに切り替えられます。日本では「やったった」、ほかの国では「Yat Tat Ta」と出し分けることもできました。今回はそうせず、全言語で同じ表記にしました。名前が国ごとに違うと、同じアプリだと分かりにくくなるからです。

  • 3語に区切ると「ヤッ・タッ・タ」の拍が見えます。ドメインのハイフンと同じ位置です。
  • 空白込みで10文字。iPhone 15 Pro のホーム画面で、省略されずに表示されることを確認しました。

04 / where

名前が出る場所は4つ

「アプリ名」と呼べるものは、iOS では別々の設定に分かれています。今回さわるのは1つだけです。

場所値決める所今回
ホーム画面Yat Tat TaINFOPLIST_KEY_CFBundleDisplayName設定した
App StoreYat Tat TaApp Store Connect登録するときに入れる
Bundle Identifiercom.yat-tat-taPRODUCT_BUNDLE_IDENTIFIER変えない
ターゲット名YatTatTaproject.yml の name変えない。仮ではなくなった

ターゲット名 YatTatTa は、前回「仮」としていました。アプリ名から空白を抜いた形になったので、このまま正式とします。

App Store の名前は、ほかのアプリと重複できません。2026-10-06 に Web 検索した範囲では、同じ名前の iOS アプリは見つかりませんでした。空いているかどうかが確定するのは、App Store Connect に登録したときです。

05 / decisions
