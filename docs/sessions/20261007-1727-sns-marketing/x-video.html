10/07 SNS で売る事例の調査 / X の縦型動画

X の縦型動画のグッドとバッド

最初に狙うのは、X の日本語のタイムライン（開発者が決定、2026-10-07）。2026-10-07 に、X が公開しているおすすめ欄のコード、X の幹部の発言、日本の個人開発の投稿を読んで調べた。投稿の数字は同じ日に第三者のミラー（fxtwitter）から取ったもので、投稿した時点の値ではない。

01 / why not

見本の1本は、なぜ訴求にならないのか

FEVER は4秒で来るし、最後は筋肉確定で終わる。型どおりに作ったのだから、少なくとも止まって見てはもらえるはずだ、と思っていました。

ところが、タイムラインで流れてくる側に立つと、見え方がまるで違います。X の動画は、音を消したまま自動で再生されます。X のプロダクト責任者は「多くの人は無音で見ている。字幕を付けるとエンゲージメントが5倍」と書いている。Yat Tat Ta の演出の半分は声です。CHANCE も激熱も筋肉確定も、無音では派手な画面が明滅しているだけになる。

もっと根の深い穴もありました。

穴1　何のアプリか分からない

映っているのは画面だけ。人がスクワットを終えて、その回数を叩く、という使い方がどこにも出てこない。動画に添える本文も、まだ書いていなかった。

穴2　叩いているのが見えない

シミュレーターの録画には指が写らない。数字が減り、画面が騒ぐのは見えても、「1打ごとに」騒いでいる手応えが伝わらない。

穴3　無音で半分が消える

声と効果音の演出が、自動再生では鳴らない。音で掴むつもりだった設計が、X では最初の1秒から効かない。

穴4　掴みが見る人の話になっていない

「食後のスクワット20回、地味すぎる。」は、食後にスクワットをしている人にしか刺さらない。そんな人は、タイムラインにほとんどいない。

02 / algorithm

X は何で表示を決めているか

動画なら、最後まで見られた割合で決まる。そう考えたくなります。2026年に X が公開したおすすめ欄のコードを読むと、そうなっていませんでした。「質のよい動画の視聴」の重みも、続きを見た秒数の重みも、初期値は 0.0 です。

効いているのは、見た人がそのあと何をするかでした。点数は「その人がその行動を取りそうな確率 × 重み」の合計です。

03 / patterns

グッドとバッド

いちばん示唆が大きかったのは、ドパドリルの作者自身の投稿どうしの差です。素のプレイ動画に一段落の本文を付けた初出は38万表示。翌日、同じ作者が出した作り込んだ紹介動画（PV）は1.2万表示でした。録画しただけ、は悪くなかった。何が起きるアプリかを本文で言い切り、動画の中で演出が膨らんでいく。この2つがそろっていたかどうかの差に見えます（因果は確かめていない）。

GOOD

  1. 1. 本文の一段落で、何に何をかぶせたかと、山場を言い切る
    ドパドリルの初出の型。Musk も「面白い説明を添えた投稿は配信される」と書いている。
  2. 2. 動画は静かに始め、膨らませ、山場で終える
    伸びたプレイ動画（53秒、72秒）はどちらも流れそのもの。説明する PV は伸びなかった。
  3. 3. 無音でも分かる文字を重ねる
    自動再生は無音が既定。声の演出があるアプリほど要る。
  4. 4. 縦型 9:16、10秒を超えて60秒以内
    2026年2月の没入型プレイヤーは縦型を切り取らずに全画面で出す。伸びた例は30〜72秒。いちばん効く長さは確かめられていない。
  5. 5. 人に送りたくなる、言いたくなる一点を入れる
    共有20、引用と返信5（表1）。ドパドリルは「○○版を作った」という改造と引用の連鎖で広がった。

BAD

  1. 1. 画面を録っただけで、本文にも画面にも「何のアプリか」がない
    X の幹部「投稿はそれだけで成立する内容に」。見本の1本がこれだった。
  2. 2. 機能と使い方を説明する紹介動画
    ドパドリルの PV は1.2万表示。同じ作者のプレイ動画は38万と47万。
  3. 3. 声と効果音に頼る
    無音の自動再生で、演出の半分が消える。
  4. 4. 同じ話題を数時間おきに連投する
    2本目から点数が下がる仕組みがある。PV の失速は、2時間前の投稿と重なっていた。
  5. 5. 刺激の言葉だけで、中身が分からない本文
    「脳汁あふれる」だけの別のドパ系の投稿は、フォロワー4.7万で1.2万表示（1例だけなので根拠は弱い）。売り込みに見えると、興味なしとミュートで大きく減る。

言われているが、根拠が弱いもの

  • 「リンクはリプ欄に」：X の幹部と Musk が、2026-07 に「もう要らない、ペナルティは1年以上前からない」と書いた。本文にリンクを入れた個人開発の投稿でも215万表示が出ている。ただ、リンク先へ飛ばれると投稿への反応が減る理屈は、幹部自身が認めている。
  • 「最初の3秒で離れられると評価が下がる」：業者の主張で、コードでは確かめられない。コードにあるのは、止まって見たら +0.05、素通りされたら −0.02 だけ。
  • 「Premium は表示が何倍」：公開中のコードに倍率は見当たらない。公式にあるのは「返信が上に出やすい」まで。

05 / next

Yat Tat Ta の次の1本

提案です。発信の決まり事の1（健康の効果を書かない）と2（パチンコの語を書かない）を守っています。

本文の案

食後のスクワット、終わったら回数だけボタンを叩くアプリを作りました。 叩くたびに演出がインフレして、ときどき FEVER。最後の1打で「筋肉、確定！」と叫ばれます。 地味な20回が、毎回お祭りになる。 App Store：（公開後のリンク） #個人開発

「何に（食後のスクワット）、何をかぶせたか（叩くたびに演出がインフレ）、山場（FEVER、筋肉確定）」の順。ドパドリルの初出の型に合わせた。リンクは本文に入れる。

動画の流れの案（約20秒）

  1. 0〜2秒　寝ているスクワットマン。文字「スクワット、終わった？」
  2. 2〜4秒　文字「1回＝1打」。叩いた場所に指の印が出て、1打ずつ数字が減る
  3. 4〜10秒　CHANCE、激熱と膨らむ。声の言葉は画面の文字で見える
  4. 10〜15秒　FEVER。文字「5秒間、叩き放題」
  5. 15〜20秒　筋肉確定。最後に「Yat Tat Ta」とアプリのアイコン

この流れで2本めを作った（2026-10-07、24秒）。文字は画面にかぶせず、上の帯に出した。作り方はセッションのページ。

見本の1本からの直し：叩いた場所の印（穴2）、無音でも読める文字（穴1、3）、見る人に向けた掴み（穴4）、山場を後ろへずらして膨らみを見せる（GOOD 2）、終わりにアプリ名。

出し方

  • 公開日の21〜22時台に1本（平日に X が最も見られる時間帯。ビデオリサーチ）。押し上げの実験は投稿から2時間以内が対象なので、人の多い時間に出す意味はある。
  • 同じ話題を、その日のうちに重ねて出さない。
  • 付いた返信には返す。相互フォローの返信は重みが大きい。
  • ハッシュタグは #個人開発 の1つだけ。効くかどうかは確かめられていない。
