01 / success

成功事例

日本の事例が4件、海外が6件。規模は、1人か、2〜3人の小さなチームに絞った。★は Yat Tat Ta にいちばん近い事例。

S1

よりしろ

日本 / X / 1人

Claude API で、認知行動療法の考え方を使って自己分析する日記。月額480円と980円。

やったこと
「4か月かけて個人で作った」というリリース告知を、X に1本だけ投稿した。拡散は翌日の夜から加速した。
数字
翌日に600DL、ランキングは圏外から50位へ。その翌日から 60 → 29 → 13 → 13 → 7件/日。2週間で731DL、課金59件。流入はほぼすべて X から。PR TIMES での配信（約90社）は、ほぼ反応なし。
効いた理由と教訓
作り手の物語と、共感を呼ぶ題材が重なった。課金に進む割合は高かったが、本人がいちばんの課題に挙げたのは「見つけてもらう仕組み」だった。

出典 note.yokoichi.jp

S2

IsTalk - トーク分析

日本 / TikTok と友達の紹介 / 1人

LINE のトークを分析して、結果を見せるアプリ。

やったこと
「85%の人は TikTok か友達の紹介で知った」と本人が書いている。ストアのスクリーンショットを作り直し、見た人が DL する割合を 24.2% から 37.5% に上げた。
数字
ユーティリティで1位（2024年3月）。新しい利用者が月20万人近く。サブスクは4,600人超、月の収入は250万円（サブスクと広告）。
効いた理由（推定）
分析の結果が、人に見せたくなる画面になっている。どんな動画が伸びたかは有料の部分にあり、未確認。

出典 note.com/keitaaaan

S3

ポルン

日本 / X・TikTok ほか / 1人

iOS のプライベートブラウザ。

やったこと
X と TikTok で発信した。ただ「ほとんどの投稿は無風」で、ネタを考え続けるのが重かったという。並行して、ランディングページ、検索向けのブログ、タイトルとサブタイトルの調整、レビューへの返信を続けた。
数字
約3年で10万DL、月に使う人が3万人。カテゴリの最高は11位。
教訓
SNS は当たり外れが大きい。効いたのは、地味な施策を何本も並べて続けたこと。「宣伝をしない多言語対応」は、やらなくてよかったと書いている。

出典 revent.8card.net

S4

ねこあつめ

日本 / Twitter の口コミ / 小さなチーム

庭に来る猫を眺めて、写真に撮るゲーム。

やったこと
広告はほとんど打っていない。遊び方が「スクリーンショットを撮ること」そのもので、撮った画面がタイムラインに流れた。
数字
目標は半年で5万DLだったが、2015年3月に150万DL。7,000回以上リツイートされた投稿もある。チームの人数は未確認。
効いた理由
遊んだ結果が、そのまま投稿したくなる絵になる。

出典 weekly.ascii.jp

S5

Wordle

海外 / Twitter / 1人

1日1問、全員が同じ単語を当てるパズル。

やったこと
利用者が勝手に始めた「絵文字のマス目で結果を貼る」遊びを、作者が Share のボタンとして取り込んだ。マス目は答えを明かさない。
数字
2021/11/1 に90人、2022/1/2 に30万人超、翌週に200万人超。1/1〜13 に Twitter で120万回共有された。NYT が買い取った。
効いた理由
共有の形を作者が発明したのではなく、利用者がすでにやっていることを公式にした。

出典 Wikipedia: Wordle

S6

Flappy Bird

海外 / YouTube / 1人

画面を叩いて鳥を飛ばす、極端に難しいゲーム。

やったこと
本人の宣伝はツイート数件だけ。半年以上は反応がなかった。火が付いたのは、有名な YouTuber のレビュー動画からだった。
数字
2013年5月に公開し、2014年1月に米国・中国・英国の無料ランキングで1位。最盛期の広告収入は1日約5万ドル。2014/2/10 に本人がストアから下ろした。
効いた理由と教訓
失敗の場面が、人に見せたくなる絵だった。一方で、過熱は作者を消耗させた。

出典 Wikipedia: Flappy Bird / Rolling Stone

S7

Locket Widget

海外 / TikTok と友達の招待 / 始めは1人

友達のホーム画面に、写真を直接届けるウィジェット。

やったこと
自分の TikTok に使い方の動画を出した。有料のインフルエンサーも、TikTok の広告も使っていない。
数字
2022/1/1 に公開。自分の動画は数日で約10万再生、英国の利用者の動画は1日で500万再生超。1/10 に米国の総合1位、1/11 に登録200万人超。
効いた理由
友達を招かないと使えない。ホーム画面に写真が届く様子は、画面を見せるだけで伝わる。

出典 TechCrunch

S8 ★

Pushscroll

海外 / TikTok・Instagram Reels / 2人

腕立てやスクワットをすると、スマホでスクロールできる時間が増える。回数はカメラで数える。

やったこと
最初の5,000ドルをインフルエンサーに使い、ほぼ空振りした。お金が尽きて自分たちで撮り始めたら、それが当たった。型は「最初の1〜2秒で問いを投げ（腕立て20回でスクロール依存が止まるなら？）、7〜10秒以内にアプリが動くところを見せる」。当たった型は、効かなくなるまで繰り返した。
数字（出典で違う）
Starter Story では、合計4,000万再生超、30万DL、月3万ドル。Braavo では、1年で収入100万ドル超、最盛期の月の売上が約10万ドル。App Store の評価は 4.7（1.8万件）。
効いた理由
「腕立て → スクロール」の3語で伝わり、撮るだけで絵になる。
真似しないこと
作る前に、既存の映像を編集して「動くアプリ」に見せた動画で需要を試している。日本では優良誤認を疑われうるし、App Store の 2.3.1（誤解を招く宣伝）とも相性が悪い。

出典 Starter Story / Braavo / App Store

S9 ★

Wayk

海外 / TikTok / 3人

腕立てなどのミッションをこなさないと止まらない目覚まし。

やったこと
Pushscroll など隣のアプリで当たっている型を、そのまま使った。「POV のキャプション、本物のリアクション、動くアプリの画面。短く、荒く」。まず自分たちで撮って効くと確かめ、それから外部の作り手に同じ型で撮ってもらった。ミッションの種類ごとに、別の掴みとして試した。
数字
30日で TikTok 2,500万再生、10万DL超、App Store 15位。収入は未確認。
教訓
「クリエイティブであろうとするのをやめた」。Reddit と Twitter はまったく効かず、効いたのは TikTok だけだった。

出典 First 1000

S10

Puff Count と HabitKit

海外 / TikTok とビルド・イン・パブリック / どちらも1人

Puff Count（禁煙の支え）

自分で撮った TikTok を数百本出した。ニコチンの害を教える動画が中心。月の売上は4万ドル超で、のちに売却した。累計の利用者は80万とも100万超ともあり、出典で違う。日本語の記事にある1,200万DLは他と合わず、未確認。

出典 Starter Story / 本人の投稿

HabitKit（習慣トラッカー）

X で作る過程を公開し続け、フォロワーは1.8万。それでも本人は「成長も収入も、ストアのランキング次第」と言う。他人の YouTube 動画（100万再生超）で30秒紹介されると、米国のランキングが上がった。タイムズスクエアの看板は、測れるほどの DL を生まなかった。月の売上は1.5万〜3万ドルで、12〜1月が山。

出典 Happy Bootstrapping / Sub Club

参考：Finch（ゲーム感覚のセルフケア、小さなチーム、出資なし）。年の売上は3,000万〜4,000万ドル。公式 TikTok の最大の動画は6,340万再生。ただ、いまは Meta の広告で600本以上の素材を回している。SNS の投稿だけで伸びた例としては数えない。

出典 Sparrow

02 / failure

失敗事例

「宣伝ばかりでフォロワーが離れた」という、数字の付いた振り返りは見つからなかった。代わりに、ローンチの一発に頼った例と、お金や規約で失った例が集まった。

F1

バズは1週間で元に戻る

成功の S1（よりしろ）の続き。600DL/日が、1週間で7DL/日に戻った。PR TIMES での配信は、ほぼ無風だった。

出典 note.yokoichi.jp

F2

Product Hunt で上位でも、何も起きない

  • Reaktr（日本、1人）：その日の2位。初日のアクセス約700が毎日半分になり、約25人/日で止まった。有料の契約は0。「まだ何も起きていない」。
  • AutoRepurpose：その日の1位。2週間で客足が落ち、月の売上は0ドル。「PH の客は、自分の客ではないかもしれない」。
  • MakerPulse：支持者を集めずに出し、upvote は自分を入れて3。
  • Lifestack：週の1位。上位の他社が有料の宣伝サービスを使っているのを見て、自分も100ドル払った。残ったのは主にリンクと信用だった。

出典 Zenn (Reaktr) / Substack / Zenn (MakerPulse) / note (Lifestack)

F3

インフルエンサーに先に払って空振り

成功の S8（Pushscroll）の始まり。最初の5,000ドルは、ほぼ何も生まなかった。伸びたのは、自分たちで型を見つけてからだった。

出典 Braavo

F4

広告は「ブラックホール」

家計簿の個人開発者。Apple の検索広告に1日約10ドルを何年も払ってきた。Google の広告は半年でクリックがほぼ0。1件の DL にかかった費用は、Apple が4.36ドル、Reddit の広告が0.82ドルだった。US$0.99 のアプリなら、Apple の値でも売上の4倍を払う計算になる。

出典 Substack

F5

Reddit で連投して、永久 BAN

いくつものアカウントで、同じ製品に触れる投稿を続けた。最初のアカウントは約5週間で永久 BAN、投稿30件が消された。健全なアカウントを育て直すのに5か月。本人の教訓は「製品に触れる投稿は全体の1〜2割まで」「60日以上ふつうに参加してから」「仲間の upvote は見抜かれる」。

出典 Indie Hackers

F6

見ている人が、客ではない

Indie Hackers の投稿が500回読まれ、コメントが50件付いた。客は0人。「開発者からの拍手は、投稿の出来を測っているだけ」。HabitKit の作者も、売上を公開したら、似たアプリが出てきたと話している。

出典 Superframeworks / Sub Club

F7

出しても DL がほぼ0

半年かけた iOS アプリの初日は「数回」で、そのあとグラフは動かなかった。宣伝の記述はない。10年で68本を出した別の開発者は、定番アプリの劣化版はどれも振るわず、その年いちばん DL されたのは気分転換に1週間で作ったゲームだったと書いている。

出典 Qiita / note

F8

ステマで処分

アプリの例ではない。ステマ規制の最初の措置命令は 2024/6/6、高評価の投稿を条件に割引した医療法人だった。その後も、インフルエンサーの投稿（RIZAP の chocoZAP、2024/8）、Google マップの高評価と引き換えの割引（2025/3）などが続き、2024年度は6件。処分されるのは頼んだ側で、頼まれた側ではない。

出典 AdverTimes / AdverTimes / 牛島総合法律事務所 / 消費者庁
