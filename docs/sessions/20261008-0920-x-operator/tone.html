03 / 研究の紹介

誇張しないと、伸びないのか

研究の紹介で伸びているアカウントには、見出しで言い切る型が多くあります。「〜と判明」で始め、最後に条件を明かす。科学ライターからは、この構造そのものへの批判が出ていました（投稿）。

では、誇張しないと読まれないのか。英国の大学の健康のプレスリリースを調べた研究では、誇張しても報道の量は増えず、ただし書きを付けても減りませんでした（Sumner ら 2016）。報道についての研究なので、X の伸びに当てはまるかは確かめられていません。それでも、ただし書きをオチに使う型（型C）を置く理由にはなります。

05 / check

見本の論文を確かめたこと

  • Nagasaki ら 2021（J-STAGE）：健康な成人男性15人。75g のブドウ糖の飲み物のあと、120分あおむけで休む日と、30分後にスクワット10回×3セット（速いテンポと遅いテンポ）をする日を比べた。どちらのスクワットも血糖値が低く、遅いテンポのほうが低かった。要旨と見本が合っている
  • Gao ら 2024（JYX）：過体重と肥満の男性18人（21.0 ± 1.2歳）。8.5時間すわり続ける日、30分まとめて歩く日、45分ごとに3分歩く日、45分ごとにスクワットで休む日を比べた。どの対策も食後の血糖値の上がり方を小さくし、こまめな2つはまとめて歩くより良かった。調査の下書きは対象の体重の条件を省き、スクワットの休みを「3分」としていた。要旨にないので、見本では直した
