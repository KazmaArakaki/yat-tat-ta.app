10/08 X の広報担当AI / 事例

AI で運用した X アカウントの事例

2026-10-08 に Web で調べた。個人開発か小さなチームの X のアカウントを、AI で自動か半自動で運用した例。数字には出典を付けた。自動化の道具を売る会社の記事や、ノウハウを売る note の数字は、確かめられないものとして分けた。

01 / summary

人が見ていれば、止められない？

AI が書いても、人が1件ずつ見てから出せば安全だ。設計のときは、そう考えていました。

ところが、AI が運営するサービス群のアカウント @LainAgent_AI は、自己紹介で AI だと名乗り、投稿の間を1時間以上あけ、1件ずつ人が承認していたのに「自動化した振る舞い」で凍結されました。本人の言葉は「決まった間隔と、名乗った身元こそが、検知器には有罪の信号に見える」。1日1件だけ API で出していた note の書き手も、60日で凍結されています。

人の承認が守るのは、文の中身です。凍結を分けたのは、別のものでした。公式の API だけを使っているか。返信の出し方。URL だけの投稿や、毎日同じ時刻の投稿ばかりになっていないか。投稿のほかに、人らしい動きがあるか。

そして、アプリ専用のアカウントを AI で運用して、DL や売上まで出した日本の個人開発の例は、見つかりませんでした。

03 / failure

うまくいかなかった例

事例起きたこと原因と振り返り
@LainAgent_AI「自動化した振る舞い」で凍結AI だと名乗り、間を1時間以上あけ、1件ずつ人が承認していた。異議の結果は書かれていない
KamichikaAPI で1日1件の AI の投稿。60日で凍結（のちに解除）URL ばかり、外へ誘う、機械的な型、投稿のほかの動きがない、交流がない。「中身より、アカウントの振る舞い全体を見られている」
Atlas WhoffAI に30日任せ、65本以上を自動で投稿。売上は$0人はほぼ関わらなかった。「積み上がるが、30日では効かない」
X のサンプルの issue #213公式の API（従量課金）で読む・出す・いいねをしていた開発者の凍結が相次いだ、という報告2026年2月のスパム対策の後とされる。異議は定型文で退けられた。X からの答えはない
taupe.siteAPI のクレジットが切れて自動の投稿が止まった。画面の自動操作に替えかけ、ルール違反に気づいて戻した「人が見ている」と「公式の API だけを使う」は、別々に問われる
AI の返信ボットの一斉削除2026-07-25 に4.2万を削除。1月からで170万X の幹部「人が介さずに AI でプログラム的に人と関わるのは、私たちの使命に反する」。本物の人も巻き込まれた
日本の公式アカウントの AI 画像神社がアイコンを AI の絵に替えて批判され、謝罪してアカウントを消した（2025-03）。ほかにも公式の AI 画像に反発どれも文ではなく画像。「公式が手間を AI で省いた」ことへの反発
Microsoft Tay（2016）ひとりで返信するボットが、荒らしに誘われて差別的な投稿。16時間で止めた人の確認なしで返信させると、悪意のある相手に乗っ取られる

04 / rules

設計にかかわる X の決まり

  • AI が書いた返信は、X の事前の承認が要る。開発者向けガイドラインに「承認のない AI の返信は、中身が役に立っても違反」とある。承認は Policy Support のフォームで申し込む。人が見てから出す AI の下書きが、これに当たるかは書かれていない（未確認）。
  • API からの返信は、相手がメンションか引用をしてきたときだけ（2026-02-23 から。従量課金も対象）。返信でない投稿は変わらない。
  • 自動化したアカウントは Automated のラベルを付け、人のアカウントとつなぐ。自動の返信は、相手が先に関わってきたときだけ、1回のやり取りに1件まで。
  • 公式の API のほかの自動化（画面の操作、スクレイピング）は禁止で、永久凍結の対象。
  • X の API には下書きを保存する口がない。人の承認の仕組みは自分で持つ。

05 / disclosure

AI だと名乗ったアカウントは、どう受け止められたか

名乗ったことで嫌われた、という文の例は見つかりませんでした。Truth Terminal は AI のキャラクターとして約25万人に追われ、副業のアカウントは「明かしたら信頼が上がった」と書いています。反対に、正体を隠して体験談をでっち上げた AI のアカウント群は、暴かれて批判されました。

日本で強い反発を受けたのは、どれも公式のアカウントが AI の画像を使った例です。Yat Tat Ta の動画はシミュレーターの録画で、AI の生成ではありません。ただし、X の自動の判定が「AI で生成」のラベルを誤って付けた報告はあります。

日本の企業や自治体で「中の人は AI」と名乗って X を運用している例は、探した範囲では見つかりませんでした。
