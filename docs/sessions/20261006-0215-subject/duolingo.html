02 / streak

連続記録（Streak）

Duolingo の連続記録は、もとは「その日の目標 XP を達成した日」を数えていました。それを「1レッスン終えた日」に変えたところ、7日続く人が4割以上増え、14日後の継続率も 3.3% 上がっています。数えるもの自体は同じで、条件の高さだけを変えた結果です。

途切れないための道具も、何種類も用意されています。

  • Streak Freeze（休んでも途切れない権利）

    事実同時に持てるのは2個まで。上限を1個から2個に増やしたら、1日あたりの利用者が +0.38%。入手はアプリ内通貨 Gems での購入。

    blog.duolingo.com/how-duolingo-streak-builds-habit/

  • Weekend Amulet（週末は休んでも途切れない）

    事実提示された人は、1週間後に戻る確率が4%高く、連続記録を失う確率が5%低い。利用者は週末に5〜10%落ちる。

    blog.duolingo.com/how-streaks-keep-duolingo-learners-committ

  • Streak Wager（7日続けると Gems が増える賭け）

    事実7日後の継続率が +14%。

    blog.duolingo.com/how-streaks-keep-duolingo-learners-committ

  • 連続記録のアニメーション

    事実導入で新規ユーザーの継続率が +1.7%。節目の日には特別な演出が出る。どの日数が節目かは未確認。

    blog.duolingo.com/how-duolingo-streak-builds-habit/

  • Streak Repair、Streak Goal、Perfect Streak

    二次途切れたあと Gems で1回だけ直せる。最初に 7、14、30日から目標を選ぶ。Freeze を使わずに続いた週は、炎が金色の縁取りになる。

    duolingo.fandom.com/wiki/Streak_Society

  • 日の境目

    二次アカウントのタイムゾーンの午前0時。アプリを使うと端末のタイムゾーンに合わせて更新される。公式ヘルプは未確認。

    duolingo.fandom.com/wiki/Streak

03 / weekly

XP と、週のリーグ

連続記録が「毎日」を支えるなら、リーグは「週」を支えます。似た時期に XP を稼ぎ始めた30人を1組にして、週ごとに上位を上のリーグへ上げ、下位を下げる。導入後、総学習時間は17%伸び、週5日以上かつ1日1時間以上学ぶ人は3倍になりました。

  • Leagues（週次リーグ）

    事実総学習時間 +17%。週5日・1日1時間以上の人が3倍。

    www.lennysnewsletter.com/p/how-duolingo-reignited-user-growt

  • リーグの仕様

    二次30人1組。Bronze から Diamond まで10段階。日曜夜に締めて月曜に組み直す。

    duoplanet.com/how-to-win-duolingo-league/

  • Daily Goal と XP Boost

    二次1日の目標 XP は 1、10、20、30、50 から選ぶ。XP Boost は15分間 XP が2倍。

    www.makeuseof.com/duolingo-xp-how-boost/

04 / notifications

通知

通知の文面は、手書きのひな形から、反応を見ながら効くものを選ぶ仕組み（多腕バンディット）で選ばれています。同じ文面を続けると効き目が落ちるため、最近送った文面は選ばれにくくする。これで1日あたりの利用者が +0.5%、新規ユーザーの継続率が +2% でした。

意外なのは、いちばん効いた文面です。しばらく使っていない人に「このリマインダーは効いていないようなので、しばらく止めます」と送る。通知をやめると告げる通知が、最も人を戻しました。

  • 文面の選び方

    事実多腕バンディット。最近送った文面に減点（半減期15日）。成果は「送ってから2時間以内にレッスンしたか」。

    research.duolingo.com/papers/yancey.kdd20.pdf

  • 止める通知

    事実Duolingo の幹部 Cem Kansu の発言。止めるまでの日数は未確認（二次情報では約1週間）。

    x.com/cemkansu/status/1301267132009848832

  • 深夜の「連続記録が切れそう」通知

    事実効果が大きかった。通知の本数は、正当な理由なしに増やさない方針。

    www.lennysnewsletter.com/p/how-duolingo-reignited-user-growt

05 / criticism

裏目に出るところ

連続記録は、伸びている間は効きます。途切れた瞬間は別です。記録が途切れたと示された人は、その行動を続ける率が約66%から約58%に下がった、という研究があります（Silverman と Barasch、2023年）。

  • 途切れたあとの逆効果

    事実続ける率が約66%から約58%へ。

    www.psychologytoday.com/us/blog/ulterior-motives/202306/how-

  • 数字を守ることが目的になる

    二次本来の目的が抜け落ちる「streak creep」の指摘。

    thedecisionlab.com/insights/consumer-insights/streak-creep-t

  • 罪悪感をあおる作り

    二次「Duo が悲しんでいる」通知。失う不安を作り、課金で解消させる構造。

    screenwiseapp.com/guides/duolingo-streaks-and-anxiety-in-kid

06 / porting

Yat Tat Ta に持ち込めるか

Yat Tat Ta は1人用で、サーバーも他人のデータもなく、ドパには使い道がありません。この3つの条件で、Duolingo の仕組みは大きく2つに分かれます。採否はセッションページの 06で決めました。

持ち込める

  • 低い継続条件（1日1回の完了連打）
  • 休んでも途切れない権利（通貨で買う代わりに、続けた日数で配る）
  • 節目の演出
  • 週の区切り（相手を先週の自分にする）
  • 端末の中だけで出せる通知

持ち込めない

  • リーグ、友達との連続記録（他人が前提）
  • 通貨で直す、通貨を賭ける（使い道を作らない）
  • XP が2倍になる時間（1ドパが1回でなくなる）
  • 文面の自動最適化（サーバーと大勢の利用者が要る）
  • 罪悪感をあおる通知（逃げ場のない1人用では逆効果）
