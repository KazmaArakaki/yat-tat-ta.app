「ドパ〇〇」アプリ調査

ひとことで

ドパ〇〇は、ドリルや電卓のような普通の道具に、パチンコやお祭りのような過剰な演出をかぶせたアプリ群です。
操作するたびにドーパミンが出るよう設計された、ネタ寄りの作品です。
2026年9月下旬、個人開発とAIの界隈で連鎖的に量産されました。

退屈な道具 × 過剰演出 = ドパ〇〇 （中身は普通に正しく動く）
名前
「ドパ」＋元の道具名。ドパドリル、ドパ電卓、ドパ九九など。
下地の言葉
Z世代スラング「ドパガキ」。即時報酬に弱い若者の自虐語で、2025〜2026年に拡散。
増え方
ソースを公開し、他の人がフォークして改造する。バイブコーディングで作られた例が多い。

03 / cases

事例5つ

「画面イメージを見る」の先は、公開仕様をもとにした再現モックです。実際のスクリーンショットではありません。

ドパドリル

算数ドリル／流行の中心

正解するたびに「ドパ」がもらえ、問題が進むほど演出がインフレしていく算数ドリル。

  • 演出インフレ：演出強度 E が序盤 0.08 から終盤 1.0 へ。最後は4種のフィナーレ。
  • ドパ値は対数で管理し「億」まで膨らむ。コンボ倍率は最大2倍。
  • ゲームオーバーなし。誤答は紫の点線枠で示すだけ。

作者 gear machine（@grmchn4ai）。ブラウザ完結、依存なしの ES Modules、音は Web Audio 合成、保存は localStorage のみ。58スキル（小1〜6）、トロフィー306種。PV と攻略本 PDF を作り、ラクスルで物理本まで刷った。

ドパ電卓

電卓／Flutter

普通の四則演算なのに、= を押した瞬間だけパチンコ風の煽り演出が走る。

  • 演出ランクは NORMAL／CHANCE／激熱／PREMIUM の4段。
  • 結果が 7、77、777、7777、8192 なら強制 PREMIUM。0 なら「全消灯」。
  • 効果音は合成 PCM とハプティクス。Reduce Motion に対応。
画面イメージを見る →

ドパ九九

九九／タイムアタック

九九を1問5秒以内に答え続ける。ミスか時間切れで終わり。

  • 連続正解で「ドパレベル」が Lv0〜8 に上がる。
  • 20連続で「ドパタイム」突入、50連続で「虹ドパ」確定演出（タイマーが1.5秒止まる）。
  • ひかえめモードあり。明滅は1秒3回まで、粒子は800個（スマホ400）まで。

ドパにゃん！脳汁タイピング

タイピング／fork

ドパドリルを改造したローマ字タイピング。打つたびに猫がキーを踏む。

  • 「ねこふんじゃった」が1音ずつ鳴り、速く打つほどテンポが上がる。
  • 30コンボで FEVER、60コンボで「マタタビモード」。ときどき金色の LUCKY。
  • 11曲、楽器5種を Web Audio で合成。結果画像を保存して共有できる。

ドパ将棋！

将棋／周辺事例

手番の概念がない将棋。演出ではなくルールのほうでドパを出す。

  • 相手を待たず、リアルタイムに指し進める。
  • 対局後に「ドパガキ度」と16種の「ドパタイプ」を診断。
  • 「歩兵突撃型」「カウンター型」などの戦法が生まれた。

04 / patterns

共通する設計パターン

子どもにドーパミンを浴びせるドリル、と聞けば依存を狙った作りを想像します。
ところがドパドリルの仕様を読むと、課金もランキングもありません。
分析者はこれを「ドーパミンハックではなく、快感の連鎖を壊さない習慣化ゲーム」と評しています。

体験をつくる

  1. 01退屈な道具 × 過剰演出。中身は普通に正しく動く。
  2. 02即時フィードバック。入力した瞬間に反応する。
  3. 03演出のインフレ。進むほど強くなる。
  4. 04コンボと倍率、巨大に膨らむ数値。
  5. 05失敗を罰しない（ドリル系）か、タイムアタックの緊張（九九）。

演出の文法と配り方

  1. 06確定演出と節目演出。先バレ、激熱、PUSH、虹などパチンコの文法。
  2. 07音は Web Audio で合成し、外部素材を持たない。AIの1回の生成で完結しやすい。
  3. 08安全弁。Reduce Motion、ひかえめモード、明滅上限。
  4. 09ソース公開と改造による増殖。

05 / why now

なぜ2026年9月に流行ったか

調査メモの考察。裏付けのある因果ではない。

1

共通語があった

「ドパガキ」の流行で、説明なしに通じるネタの土台ができていた。

2

AIで一気に作れる

Opus 5.5 などで演出も効果音もBGMもまとめて生成できる。演出盛りはAIの見せ場になる。

3

皮肉と実用の両義性

「勉強 × ドーパミン」は笑えて、しかも使える。拡散されやすい。

06 / cautions

作るときの注意点

明滅と音量

光の明滅は光過敏の人に負担になる。ドパ九九は明滅を1秒3回までに抑え、ドパ電卓は Reduce Motion に従う。音量にも配慮が要る。

依存批判

子ども向けで依存を煽る設計は、ダークパターンとして批判されうる。ドパドリル系は課金、ランキング、可変報酬を持たないが、見た目だけで判断される可能性は残る。

性能

演出を盛るほど端末は重くなる。ドパ九九ではスマホで音が詰まり、入力が遅れた。

07 / if we build

作るなら

2026-10-05 に開発者と合意した方針。

形式
ネイティブアプリ
事例5本のうち4本は Web。ネイティブはドパ電卓（Flutter）だけ。拡散なら Web が強いが、差別化のためにネイティブを選んだ。
対象
まず iPhone のみ
開発者本人が iPhone を使っているため。
技術
Swift（SwiftUI）
Flutter は2つの OS に出すときに利点が効く。iPhone だけなら効かないので見送った。

差別化の本体

4つがずれずにそろう手触り

  1. タップ
  2. →
  3. 音
  4. →
  5. 振動
  6. →
  7. 光

Web の事例では、音が詰まって入力が遅れた例もある（ドパ九九）。ずれの小ささそのものを売りにする。

1

Core Haptics

演出と振動を細かく同期できる。差別化の中心。

2

AVAudioEngine

音の遅れを抑えやすい。

3

描画の選択肢

SwiftUI のアニメーション、SpriteKit、Metal が使える。

Claude

コードはすべて書く

  • Claude Code を Mac 上で直接動かす。
  • XcodeGen・xcodebuild・xcrun simctl・xcrun devicectl を使う。
  • Linux のコンテナでは iOS をビルドできない。

開発者

Claude にできない3つ

  1. 01初期設定。Xcode を入れる、Apple ID でサインイン、iPhone のデベロッパモードをオン、開発者を信頼。
  2. 02実機で手触りを確かめる。Claude は振動も音の遅れも感じ取れない。シミュレーターでは振動が出ない。
  3. 03ストアに出すなら、Apple Developer Program（年額有料）への登録と App Store Connect への提出。
  • 無料の Apple ID だと、約7日ごとにアプリを入れ直す必要がある。
  • Android に出すことになったら作り直しになる。
