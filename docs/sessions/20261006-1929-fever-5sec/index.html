フィーバータイムを5秒にする

結果（レビュー済み）

10秒 → 5秒
ラッシュ 3秒 → 2秒

10秒は長かった。
叩き続けるうちに指が疲れ、最後のラッシュに着くころには勢いが落ちている。
半分の5秒なら、息を止めたまま叩き切れる。

01 / design

変えるもの、変えないもの

変えるのは長さだけです。当たる確率 0.51%、1打1ドパ、終わったあとの「FEVER 終了」の1.6秒は、どれもそのまま。 ラッシュは最後の3秒から2秒に縮めました（開発者が決定）。3秒のままだと5秒の過半がラッシュになり、始まって2秒で「ラッシュ！」が鳴ってしまう。 2秒なら、最初の3秒で叩き放題に慣れ、残り2秒で畳みかける配分になります。

場所変更なぜ
MashSession.feverDuration10 → 5長さの元。画面の残り秒数、BGM の切り替え、終わる時刻はすべてここから引く
MashSession.feverRush3 → 25秒の過半がラッシュにならないように
AppModelTestsラッシュの1打を 8.0秒 → 3.0秒8秒ではフィーバーが終わっているため
FeverOverlay / AppModel / PerfSeedTestsコメントの「10秒」「最後の3秒」挙動は変わらない
docs「10秒」を「5秒」に、ラッシュの「3秒」を「2秒」に完了連打、用語集、フィーバーの見本、処理落ちの確かめ方

保存するデータは変わりません。記録の bonusDopa は取ったドパをそのまま入れるだけなので、これまでの記録も読めます。
