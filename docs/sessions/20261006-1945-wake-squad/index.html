長押しで隊を起こす

開発者の注文

寝ている → 長押しで起きる → 叩いてしゃがむ

今は、叩く場所に指が触れた瞬間に記録が開く。
ポケットの中で画面に触れても、1打目になってしまう。
隊を寝かせておけば、起こす手間がそのまま誤タップの防ぎになる。起き上がる動きは、見ていておもしろい。

01 / motion

動きの見本

6秒で1巡します。寝ている1人を長押しで起こし、目標4回を叩き切って、倒れ込んで寝るまで。ピンクの点は指の位置で、画面には出ません。

  1. 0.0〜1.0秒

    寝ている

    短く叩いても起きない。数えない。

  2. 1.0〜1.5秒

    押している

    手足をばたつかせ、上半身が起きてくる。

  3. 1.5秒

    起きた

    立って小さく跳ねる。短い振動と音。

  4. 2.4〜3.3秒

    叩く

    ここからは今までどおり。

  5. 3.3秒

    残り0

    最後の1打で倒れ込み、寝る。

02 / spec

決めたこと

長押しの長さを先に決めました。0.5秒、iOS の長押しと同じです。 短くすると、画面をかすめた指でも届いてしまう。長くすると、毎食後に叩くたび連打の前で待たされる。 押している間に何も変わらなければ、どれだけ押せばいいか分からないはず。そこで目盛りの代わりに、隊の体が少しずつ起きてくる形にしました。

場面決めなぜ
叩いていない間1人が床に寝ている。下の文言は「長押しで起こす」叩いても始まらないことが、見て分かる
短く叩いた何も起きない。数えない誤タップを防ぐのが目的
押している手足をばたつかせ、上半身が起きてくる押し続ければ起きると分かる。進み具合の目盛りを兼ねる
0.5秒前に離したパタンと寝直す起きなかったことがはっきり見える
0.5秒に届いた立ち上がって小さく跳ねる。短い振動と音。文言は「叩いてしゃがむ」叩いてよい合図。指を離す前に分かる
起こした指数えない。起きてから触れた指だけを1打にする起こすのは準備で、スクワットの1回ではない
残りが0になった最後の1打で隊が倒れ込み、1人に戻って寝る。最後の1打でフィーバーが当たったら、フィーバーが終わってから叩き切ったら力尽きる。次の記録も、起こすところから始める
時間がたった寝ない。起きたまま叩かなくても、60秒止まって記録が閉じても、アプリを離れても、起きたまま寝るのは叩き切ったときだけ（開発者が決定）。途中で閉じた記録の続きは、起こし直さずに叩ける
ひかえめモードばたつきと跳ねをやめ、姿勢だけを短く切り替える。長押しの0.5秒は同じひかえめモードの決まり。誤タップの防ぎは残す
VoiceOver寝ているときのダブルタップで起こす。読み上げは「完了連打。スクワット隊が寝ています」と、ヒントの「ダブルタップで起こす」VoiceOver では長押しが操作しにくい。「長押しで」と読み上げると、VoiceOver の操作と食い違う（実装で変えた）

保存するデータは変わりません。起きているかどうかは画面の中にだけ持つので、アプリが終了して開き直したときは寝た状態から始まります。

03 / place

完了連打のどこに足すか

足すのは完了連打の入口の1段だけです。 記録の開き方と閉じ方、1打1ドパ、ドパドパ、フィーバー、フィナーレは何も変えない。 気になったのはタッチ→発火の速さでした。 長押しを iOS の UILongPressGestureRecognizer で受けると、認識した時点で指が touchesCancelled に切り替わり、今の touchesBegan での受け方と絡みます。 そこで長押しも touchesBegan の中で時刻を測って受けます。起きてからの1打は、今と同じ道を通ります。

寝ている

tap は数えない。長押しだけを待つ

起きている

1打目で記録が開く。時間では寝ない

記録が開いている

今までどおり。残りが0になったら寝る

04 / detail

直す場所

場所変更なぜ
AppModelsquadAwake と wake() を足す。寝ていて記録も開いていなければ tap は nil。叩き切って記録が閉じたとき（close(completed: true)）だけ寝かせる。途中で閉じたときは起きたまま「寝ていれば数えない」をモデルで守る。画面の作りに頼らず、テストで確かめられる
MashSessionwakeHold = 0.5 を置くほかの秒数（idleTimeout など）と並べて1か所で変えられるように
SquatterLayer姿勢に「寝る」「起きかけ」を足す。立つ・しゃがむと同じ点の数で描く点の数がそろっていれば、今の path のアニメーションでそのまま形を移せる
SquatStageUIView寝ている間の touchesBegan で長押しを測り始め、0.5秒で wake()。早く離したら寝直す。起こした指は離れるまで数えない。最後の1打で倒れ込ませる。文言と読み上げを切り替える起きてからの1打は今の道のまま。タッチ→発火を遅らせない
FeelEngine / ToneSynth起きた瞬間の短い振動と音を1つ足す。音は ToneSynth で作り、音声ファイルは足さない指を離す前に「もう叩ける」と手で分かる。声にしないので多言語の作業は増えない
Localizable.xcstrings「長押しで起こす」と英語の Hold to wake up多言語の決まり事。文言を足すときは英語も同時に
AppModel+Demo-demo squad は叩く前に wake()寝たままでは見本の97打が全部捨てられる
テスト寝ていれば数えない、起こせば数える、叩き切ったら寝る、途中で閉じても起きたまま、を足す。今の model.tap を使うテストは先に wake()入口の決まりを壊さないため
docs完了連打、スクワット隊の見本（寝ている・起きかけを足す）、ホームの見本実装と一緒に直す。用語集の「起こす」は先に足した

06 / build

作ったところ

テストは48件すべて通った。足したのは4件で、寝ていれば数えない、叩き切ったら寝る、途中で閉じても起きたまま、最後の1打でフィーバーが当たったら終わるまで起きたまま。 シミュレーターでは、起動直後に1人が床に寝て「長押しで起こす」と出るところまで確かめた。 長押しの0.5秒、じたばた、跳ね、倒れ込みは、開発者が実機で触って OK とした（2026-10-06）。0.5秒もこのままでよい。

  • 起きた音は ToneSynth の新しい音（低い音から跳ね上がる2音）。振動は「+1人」と同じトンを使った。
  • 押している間のじたばたは、足首を軸にした小刻みな回転。上半身は0.5秒かけて一定の速さで起きる。
  • 寝た姿は、隊の真ん中に来るよう、立ったときの足首より右へずらして描く。起き上がるとき、少し左へ踏み出して見える。
  • docs は、完了連打、スクワット隊の見本（「寝ている・起こす」を足した）、ホームの見本（寝た状態から長押しで起きる）を直した。
