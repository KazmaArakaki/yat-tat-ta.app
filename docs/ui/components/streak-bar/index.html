連続記録の帯

ホームのいちばん上に置く帯です。左に連続記録の日数、右に休み券の残り。休み券は2枚分の枠を常に出し、持っていない枠は点線にします。

今日まだ叩いていない日は、日数の下に「1回で何日目か」を出します。数字を守らせる言い方ではなく、次の1回で何が起きるかを先に見せるためです。途切れたあとも「0日」とは出しません。
