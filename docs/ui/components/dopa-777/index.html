ドパ揃い

使わなくなった。2026-10-06 にドパ突破へ置き換えた（開発者の注文「777でのボーナスは不要」）。経緯として残している。

DT が100の倍数をまたいだ1打で、画面全体に重ねるスロットの演出です。パチンコの「777」の絵柄を借りました。リールが3つ回り、左から「7」で止まって揃い、虹の光と金の粒が噴き出します（ドパ揃い）。

連打の途中に出ることが多いので、重ね物は指を通します。リールを見ながらでも、後ろのボタンはそのまま叩けます。

state / hit

揃った

左から0.25秒ずつ遅れて「7」で止まる。止まるたびに「ガコン」と鋭い振動。3つ揃った瞬間に虹の光が噴き出し、金の粒が上から降る。ファンファーレと「ジャラジャラ」。

全体で2.5秒ほどで消える。くじはないので、100をまたげば必ず揃う。
