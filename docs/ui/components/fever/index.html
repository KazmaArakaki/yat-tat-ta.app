フィーバータイム

完了連打の1打ごとに 0.51% のくじで当たる、5秒間のボーナスです（フィーバータイム）。そのあいだは画面のどこを叩いても1打1ドパ（倍率は付けない）。最後の2秒はラッシュで、演出だけが強まる。スクワットの残りは止まり、終わったら続きから叩きます。

地は色の流れる放射線になり、金の粒が降り続けます。色を流す速さは1秒に1周まで、白い明滅は1秒3回まで。BGM は bgm_fever に切り替わります。
