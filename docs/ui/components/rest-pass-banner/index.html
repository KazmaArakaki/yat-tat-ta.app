休み券の帯

叩かなかった日に休み券が自動で使われたあと、最初に開いたときに上から2秒だけ出す帯です。休み券の色（青）で塗ります。

伝えるのは、つながったという事実だけです。「昨日は休みましたね」のような、休んだことを指す文は書きません。
