通知の問いかけ

初めて叩き切ったフィナーレが消えたあとに、1度だけ下から出すカードです。「知らせて」を押したときに、iOS の通知の許可を求めます。起動直後には聞きません。何をするアプリか分かる前に許可を求めても、断られるだけだからです。

知らせるのは今日まだ通知だけです。1日1回、その日まだ叩いていない夜に。
