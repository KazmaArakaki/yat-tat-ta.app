チュートリアルの案内

ホームの上に暗い幕をかけ、1か所だけを照らして、下に吹き出しを出す部品です。照らす場所は場面ごとに動きます。叩く場面では照らした場所だけを叩けて、ほかの場面では画面のどこを叩いても次へ進みます。

見本は、記録がまだ1件もなく、Apple でもログインしていない人の画面です。1つめの場面から通しで触れます。長押しでスクワットマンを起こすと練習連打に入り、10回叩くと練習のフィナーレが出ます。DPW と DT は最後まで 0 のままです。

通しの時間（目安）

0:00/ 約 1:02

    場面ごとの決まり

    場面照らす場所次へ進む合図目安
    1 スクワットマンを起こす帯とカードのあいだ（叩く場所）0.5秒の長押しでスクワットマンが起きた5秒
    2 練習連打同じ10回を叩き切り、練習のフィナーレ（筋肉確定、あんたはえらい！）が終わった12秒
    3 いまのは練習同じ（スクワットマンはまた寝ている）どこかを叩く8秒
    4 続けた日連続記録の帯どこかを叩く9秒
    5 ためたドパDPW と DT のカードどこかを叩く9秒
    6 回数を変える設定の歯車どこかを叩く6秒
    7 記録を残すなし（全体を暗く、まん中にカード）。まだ Apple でログインしていない人だけ「Appleで続ける」か「あとで」を押す。叩いても進まない8秒
    8 おわりなし（全体を暗く）「はじめる」を押す5秒
    • スキップ：吹き出しの右上に、1〜6の場面でいつも出す。まだ Apple でログインしていない人は、押すと7の記録を残すへ飛び（練習の途中なら練習を捨てる）、そこで「あとで」を押すとそのまま終わる。Apple でログイン中の人は、その場で終わる。どちらも見せたことにする。機種を替えた人ほど使い方を知っていてスキップするので、記録を戻す道だけは飛ばさない。
    • 記録を残す：ログインを求める画面に見せないよう、ログインしなくても全部使えることを同じ重さで書き、「あとで」も金色の大きいボタンにする。見本では「Appleで続ける」を押すと、引き継げたものとして8へ進む。前の記録のある Apple ID なら、本物はアカウントごと替わってチュートリアルが消え、記録の入ったホームになる。
    • 照らした場所は押せない：4〜6で帯やカードを押しても、今日の記録や履歴は開かない。どこを叩いても次へ進むだけ。開いてしまうと、シートを閉じるまで案内が止まるから。
    • ひかえめモード：照らす枠の移動と点滅、吹き出しの浮き上がりを止める。練習連打の演出は本番と同じ扱い（揺れと粒を止め、文字と色だけ）。
    • VoiceOver：場面が変わるたびに、吹き出しの見出しと本文を読む。起こすのはダブルタップ、叩くのは直接操作（いまの完了連打と同じ）。
