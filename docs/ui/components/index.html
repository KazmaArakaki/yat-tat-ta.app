ui / components

コンポーネント

アプリの画面を組み立てる部品です。どれも状態ごとの見た目を切り替えて見られます。右上の「暗い配色」で、iPhone を暗い表示にしたときの見た目に変わります。

部品は2種類に分かれます。ホームに常にあるものと、その場で上に重ねて、用が済めば消えるもの。後者はどれも1度しか出ないか、短い時間で消えます。配色や形の決まりは UI の基本方針に。

アプリの外に出るもの

logo

ロゴ

金の地にしゃがむ人形1人のマーク（アプリアイコン）と、Ta だけ dopa の名前の文字組み。

ホームに常にあるもの

squat-squad

スクワットマン

画面の主役。中央を叩くと全員がしゃがみ、離すと立つ。2回ごとに1人増える。

streak-bar

連続記録の帯

画面のいちばん上。何日続いたかと、休み券の残り。

totals-cards

DPW と DT のカード

画面の下に2枚並べる。DPW は前の7日と自己ベスト、DT は次の節目と。押すと履歴が開く。

その場で重ねるもの

tutorial-coach

チュートリアルの案内

ホームに暗い幕をかけ、1か所だけを照らして吹き出しで言う。場面ごとに照らす場所が動く。8つの場面（記録を残す場面は、まだ Apple でログインしていない人だけ）を通しで触れる。

splash

スプラッシュ

起動したときに1.65秒。続けた日を人形の隊列で並べ、波が今日の席に届いたら、数だけが帯へ飛ぶ。

finale

フィナーレ

叩き切った最後の1打で、画面全体に重ねる演出。筋肉確定、ねぎらいの順に出て、節目の札が積まれる。

dopa-toppa

ドパ突破

DT が100の倍数をまたいだ1打で、画面いっぱいに「300／ドパ突破」。指は通す。

fever

フィーバータイム

1打 0.51% で当たる5秒。どこを叩いても1打1ドパ、最後の2秒はラッシュの演出。残り秒数と合計を大写し。

dopa-777（使わなくなった）

ドパ揃い

777 のリール。2026-10-06 にドパ突破へ置き換えた。

mash-button（使わなくなった）

完了連打のボタン

金色の丸いボタン。2026-10-06 にスクワットマンへ置き換えた（04-5）。

streak-break-card

途切れたときのカード

途切れたあと最初に開いたとき1度だけ。最長記録と DT を前に出す。

rest-pass-banner

休み券の帯

休み券が自動で使われたあと、最初に開いたとき2秒だけ。

reminder-ask

通知の問いかけ

初めて叩き切ったフィナーレのあとに1度だけ。

シートの中に置くもの

history-chart

履歴のグラフ

縦に時刻、横に日付。記録1件をしゃがんだ人形1つで置き、背景に日ごとのドパと7日移動平均を重ねる。
