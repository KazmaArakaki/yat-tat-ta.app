スクワット隊

ホームのまん中に立つ、横向きの棒人間の一団です（スクワット隊）。完了連打では、上の帯と下のカードのあいだを画面の幅いっぱいに叩きます。指が触れた瞬間に全員が揃ってしゃがみ、指が全部離れたら立ち上がる。スクワット2回ごとに1人増えます（はじめは5回ごとだったが、開発者の注文で2回ごとにした）。

2026-10-06 に、金色の丸いボタンから置き換えました。ボタンは何の形でもなく、叩いているのがスクワットの記録だと目で分かりませんでした。人の形なら、1打が「しゃがんだ1回」に見えます。

線は太い ink に色を重ねた棒で、コードで描きます。画像のファイルは使いません。立つ姿としゃがむ姿のあいだを線の形ごと動かせて、画面の大きさも選ばないからです。

states

状態ごとの見た目

どの見本も、画面の中を押すとしゃがみ、離すと立ちます。

スクワット 残り

20

叩き始める前

state / stand1

1人で立つ

叩く前の待機。目標回数 20 で、隊は1人。色は gold。

叩く場所は、上の帯と下のカードのあいだの全部。見本の中のどこを押してもしゃがみます。

スクワット 残り

19

指が触れているあいだ

state / squat1

しゃがむ

指が触れた瞬間に0.08秒でしゃがむ。腰を後ろへ引き、膝を前へ出し、腕を前に伸ばす横向きの姿。

指が全部離れたら0.12秒で立つ。立ち上がりを少し遅くして、しゃがんだ形を目に残す。指を置いたままなら、しゃがんだまま止まる。

スクワット 残り

10

目標30のうち20打

state / five

11人の隊

2回ごとに1人ずつ増える。20打で最初の1人と合わせて11人。手前の列の3人が埋まると、奥の列へ。

増えた1人は足元から跳ねて現れ、「+1人」と音が出る。色は人ごとに gold、dopa、signal を回す。全員が揃ってしゃがむ。

スクワット 残り

8

目標20のうち12打

state / hot

激熱で全員 dopa

ドパドパの激熱に入ると、地が暗転して虹の放射線が回り、隊の全員が dopa 色にそろう。

色がそろうと、隊がひとつになって盛り上がって見える。

PUSH! 3

目標20のうち17打

state / push

PUSH で全員 gold と虹の輪

PUSH では全員が gold。隊の上の文字が「PUSH!」になり、残りを 3、2、1 と数える。

最後の1打で節目に届くと分かっている連打では、隊の後ろで虹の輪が回る（虹の先バレ）。くじは引いていない。

スクワット 残り

0

目標100を叩き切った1打

state / many

30人

目標回数60で30人に届き、そこで止まる（上限30人）。奥の列ほど小さく描き、大勢でしゃがんでいるように見せる。

叩き切るとフィナーレが重なり、閉じたあと隊は1人に戻る。

rules

描き方の決まり

  • 線：ink の線（太さ12）の上に、色の線（太さ6.5）を重ねる。頭は色で塗った丸に ink の縁。端と角は丸める。
  • 2つの姿：立つ姿は、つま先、足首、膝、腰、肩が縦にそろい、腕は下へ。しゃがむ姿は、腰を後ろへ引いて膝を前へ出し、上体を少し前へ倒して腕を前に伸ばす。点の数は2つの姿で同じにして、あいだを動かす。
  • 並び：手前から 3人、5人、7人、9人の列。大きさは手前を1として、0.78、0.62、0.5。列の中は真ん中から、左右へ交互に埋める。
  • 視差効果を減らす：人はしゃがむ（動きが叩いた返事そのものなので）。増えるときの跳ねだけを止める（ひかえめモードの考え方）。
