スプラッシュ

起動したとき、ホームの上に1.65秒だけ重ねる幕です。ロゴを見せる場所ではありません。これまで続けた日が、スクワットマンの人形になって曜日ごとに並び、古い日から順に1回ずつしゃがむ。その波が届く先、人形のいない床の印に上から光が差しているところが今日の席です。

上の名前は「Yat」「Tat」「Ta」と1語ずつ落ちて、着地でつぶれます。3拍めの「Ta」が、波が今日の席に届く瞬間と重なる。振動もこの3拍に合わせます。最後に大きな数だけがホームの連続記録の位置へ飛び、そのまま連続記録の帯の数になります。

インストールして最初の1回だけは、並べる日がまだありません。代わりにはじめての幕（14.0秒）で、1人の人形が「食べたら、しゃがんで、叩く」をやって見せ、今週の席に入ります。タブの「はじめての起動」で再生できます。

部品見た目なぜ
名前SF Pro Rounded の Black、30pt。「Ta」だけ dopa。1語ずつ上から落ち、着地で横に広がって縦につぶれるYat Tat Ta は「やったった」。3拍で言い切る名前を、3回のしゃがみとして見せる
隊列1日に1人。gold の体に黒い縁（スクワットマンと履歴と同じ人形）。7列で曜日にそろえ、古い日が左上、今日が右下。行の高さは最大58pt、週が増えると縮む。8週を超えたら古い週を「＋N日」にまとめる続けた日数が、数ではなく人数で見える。1行が1週間なので、休み券をもらった7日ごとの区切りも読める
休み券の日人形の代わりに signal の札人形が欠けた日を、途切れに見せない。帯と履歴と同じ札
今日の席人形はいない。床に dopa の丸い印（黒い縁 3.5pt）を置き、上から薄い光（下ほど濃い dopa、上で消える）を差す。波が届くと、輪が床の上に楕円で広がり、そのあと1.1秒周期でゆっくり濃淡を繰り返す。今日済みなら、印の上に人形が立って2回しゃがむ。ほかの人形の足元にも薄い影を落とし、印が「人の立つ場所」だと読めるようにする隊列の最後が空いている。舞台に光だけが当たっていて、立つ人をまだ待っている形。点線で人形の輪郭を描く案は、人形そのものが欠けて見え、違和感があった（開発者のレビュー）
はじめての幕高さ約220pt の人形1人と、下の1行「食べたら、しゃがんで、叩く。」。今の語だけ濃く、ほかは薄い。そのあと今週の7つの席（左端が今日、曜日の札つき、7つめは休み券）。今日の席だけ光が差し、明日からの席は床の印の輪郭（点線の楕円）だけ。明日からの6人は0.85の濃さで一瞬だけ立つ何をするアプリか、続けると何が起きるかを、文ではなく動きで先に見せる
数と一言数は SF Pro Rounded Heavy 88pt、dopa。一言は Black 15pt で、今日の席が光ってから出る。次の1回で節目に届くなら、gold の「節目」の札を添える一言は帯と同じ文。スプラッシュで読んだ文が、引き継いだあとのホームにもそのまま残る
