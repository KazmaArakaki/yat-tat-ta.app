途切れたときのカード

連続記録が途切れたあと、最初にアプリを開いたときに1度だけ下から出すカードです。途切れた直後は、やめる人がいちばん出る瞬間です。だから、失ったものより残っているものを大きく出します。

大きく出すのは最長記録と DT。どちらも途切れても減りません。「また1日目から」とだけ書いて終わらせない。
