DPW と DT のカード

画面の下に2枚並べます。左がDPW、右がDT。叩くたびに、どちらも1ずつ増えます。

DPW の比べる相手は前の7日と自己ベスト、DT は次の節目です。DT の下の細い棒は、ひとつ前の節目から次の節目までの進み具合を表します。
