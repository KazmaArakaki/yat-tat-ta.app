完了連打のボタン

ホームのまん中に置く、金色の丸いボタンです。数字は、まだドパに変えていないスクワットの数。完了連打の1打ごとに1減り、1粒のドパがボタンから下へ飛びます。

指が触れた瞬間に鳴ります（touchesBegan）。離すのを待つと、連打の速さに音が追いつかなくなるからです。最初の数字は目標回数で、叩き始めたときの値を最後まで使います。

states

状態ごとの見た目

state / idle

待機

目標回数がそのまま出る。下の「+N ドパ」はまだない。

押し込むとボタンが沈み、影が縮む。叩いた感じを、音と振動より先に目で返す。

+7 ドパ

state / mashing

連打中

20打のうち7打目。残り13、+7 ドパ。

ボタンの外側の光と、指の位置の輪は連打の速さで強まる。0.45秒以内に次を叩くと明るくなり、止まると落ちる。音の高さと振動の強さは、速さではなく進み具合（8段階）で決まる。

+20 ドパ

1.2秒は叩いても数えない

state / locked

叩き切った直後

残りが0になった1打でフィナーレが重なる。そのあと1.2秒はボタンが色を落とし、叩いても数えない。

勢い余った指で、次の記録が始まらないようにするため。

+7 ドパで1件にしました

state / reset

途中で閉じて戻る

7打で手が止まり、60秒たった（またはアプリを離れた）。叩いた7ドパで記録を1件にして、ボタンは目標回数に戻る。

フィナーレは出さない。下の一言だけが2秒残る。
