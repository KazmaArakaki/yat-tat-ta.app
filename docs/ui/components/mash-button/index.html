完了連打のボタン

このボタンは使わなくなった。2026-10-06 に、画面中央の広い叩く場所とスクワット隊に置き換えた（本作りの設計 04-5）。下は置き換える前の記録として残す。

ホームのまん中に置く、金色の丸いボタンです。数字は、まだドパに変えていないスクワットの数。完了連打の1打ごとに1減り、1粒のドパがボタンから下へ飛びます。

指が触れた瞬間に鳴ります（touchesBegan）。離すのを待つと、連打の速さに音が追いつかなくなるからです。最初の数字は目標回数で、叩き始めたときの値を最後まで使います。

states

状態ごとの見た目

state / idle

待機

目標回数がそのまま出る。下の「+N ドパ」はまだない。

押し込むとボタンが沈み、影が縮む。叩いた感じを、音と振動より先に目で返す。

+7 ドパ

state / mashing

連打中

20打のうち7打目。残り13、+7 ドパ。

ボタンの外側の光と、指の位置の輪は連打の速さで強まる。0.45秒以内に次を叩くと明るくなり、止まると落ちる。音の高さと振動の強さは、速さではなく進み具合（8段階）で決まる。

+20 ドパ

1.2秒は叩いても数えない

state / locked

叩き切った直後

残りが0になった1打でフィナーレが重なる。そのあと1.2秒はボタンが色を落とし、叩いても数えない。

勢い余った指で、次の記録が始まらないようにするため。

+7 ドパで1件にしました

state / reset

途中で閉じて戻る

7打で手が止まり、60秒たった（またはアプリを離れた）。叩いた7ドパで記録を1件にして、ボタンは目標回数に戻る。

フィナーレは出さない。下の一言だけが2秒残る。

CHANCEドパ

state / chance

CHANCE

ドパドパの2段目。目標回数 20 の6打目（進み具合30%）で入る。入った1打で「CHANCE」の帯がボタンの上を横切り、上がる音が1つ鳴る。

そのあいだ、ボタンの縁が dopa 色で脈打ち、指の位置から飛ぶ「ドパ」の文字が大きくなる。

激熱ドパドパ ×9ドパドパ

state / hot

激熱

12打目（進み具合60%）で入る。入った1打で「激熱」の判子が押され、画面が1度だけ揺れる。低い音と重い振動。

そのあいだ、背景に dopa の集中線がゆっくり回り、ボタンは赤みを帯びた金になる。この見本は0.45秒以内の連打が9打続いたところで、指の上に「ドパドパ ×9」が出ている。数は勢いだけで、ドパは増えない。

ドパァ

state / push

PUSH

残りが3になった1打（17打目）で入る。ボタンの下の文字が「PUSH」になり、残りの数を 3、2、1 と大写しにする。

目標回数が10より少ないときは、残り1打から。次の1打がフィナーレ（確定）。

state / rainbow

PUSH＋虹

最後の1打で節目に届くと、記録から分かっている連打。PUSH に入った瞬間から、ボタンの縁が虹色に回る。パチンコでいう先バレ。

くじは引いていない。今日の1回で連続30日目になる、DT が1,000を超える、といったことは叩く前から計算で分かる。
