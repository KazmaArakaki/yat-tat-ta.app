履歴のグラフ

履歴のシートのまん中に置くグラフです。横に記録日、縦にその日の時刻（午前4時から翌朝4時、上ほど遅い）。記録1件をスクワット隊のしゃがんだ人形1つで置きます。

人形の面積は、その記録のドパに比例させます（高さは平方根）。10ドパで約21pt、20ドパで約29pt、52ドパで約47pt。14pt より小さくも 46pt より大きくもしません。

背景の面は2枚です。斜線は使わず、縁の線と薄い塗りで描きます。dopa 色が日ごとのドパ、signal 色が7日移動平均。どちらも同じ目盛りで、いちばん多い日の1.15倍が上端です。目盛りの数字は出しません。

states

状態ごとの見た目

state / normal

30日分

開いた直後。今日（10/6）が右端に来て、7日ほどが見える。左へなぞると過去の日へ戻る。

朝、昼、夜の3つの帯に人形が並ぶ。dopa 色の人形はフィーバーでドパを足した記録。青い札は休み券を使った日。

state / picked

人形を押した

押した人形に点線の輪が付き、下の詳細がその記録に変わる。時刻、回数、フィーバーのドパ。上の行は、その日の件数、合計、7日移動平均。

別の人形を押せば切り替わる。消すボタンは出さない。

state / first

はじめの3日

記録を始めて3日目。列は少なくとも7日分を出すので、左の4日は空いている。

7日移動平均は、始める前の日を0ドパとして数えるので、日ごとのドパよりずっと低い。8日目から追いつく。

state / empty

記録なし

まだ1度も叩いていない。7日分の空の列と、「叩くと、ここに人形が並びます。」だけを出す。

DPW と DT のカードは 0 でも押せる。
