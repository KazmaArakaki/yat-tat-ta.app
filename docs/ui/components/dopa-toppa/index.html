ドパ突破

DT が100の倍数をまたいだ1打で、画面いっぱいに重ねる演出です。金属の数字が叩きつけられ、下に「ドパ突破」。虹の放射線が回り、衝撃波の輪が画面の端まで広がります（ドパ突破）。

2026-10-06 に、777 のリールを回すドパ揃いから置き換えました。重ね物は指を通すので、後ろのボタンはそのまま叩けます。フィーバータイムの連打でまたいでも出ます。

ドパ突破

state / normal

通常

100、200、300…と、100の倍数をまたいだ1打で出る。数字が3倍の大きさから叩きつけられ、0.12秒遅れて「ドパ突破」。声 voice_toppa とファンファーレ、鋭い振動。

1.5秒ほどで消える。連打の途中でもボタンは叩ける。

state / gold

金（1,000以上）

DT の節目（1,000、1万、10万）にあたる1打では、放射線も文字も金になり、金の粒が降る。節目の札も出る。

state / reduced

視差効果を減らす

iPhone の「視差効果を減らす」が入っているとき。放射線と衝撃波を止め、文字は叩きつけずに置くだけにする（ひかえめモードの考え方）。音と振動は変えない。
