フィナーレ

残りが0になった最後の1打で、ホームの上に重ねて出す演出です。粒が弾け、「やったった！」の文字が跳ね、和音と長めの振動が鳴ります。これがフィナーレで、叩き切れば毎回出ます。

その1打で節目に届いていれば、文字の下に札が1枚ずつ積まれます。札1枚ごとに金色の粒と音が1つ増える。3枚がそろう1打が、いちばん重い場面です。
