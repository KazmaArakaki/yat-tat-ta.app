ログイン画面

まだアカウントでログインしていない人が、起動して最初に見る画面です。ボタンは「Appleで続ける」の1つだけ。ログインが済むと、いまどおりスプラッシュからホームへ進みます。

床で寝ているスクワットマンは、ログインすると起き上がります。ホームで長押しして起こすのと同じ姿で、このアプリでは「寝ている＝まだ始まっていない」です。ボタンを押すと、このモックでも起き上がります。

プライバシーポリシー

  • Appleで続ける：iOS の標準のボタン（SignInWithAppleButton、種類は continue）。文字と形は Apple の決まりどおりで、色だけ配色に合わせて黒と白を替える。
  • つないでいる：ボタンの文字が回る印に替わり、押せなくなる。Apple のシートを閉じたら、はじめに戻る。
  • つながらない：ボタンの上に1行だけ出す。初めてのログインだけは電波が要る。2回目からはログインしたままなので、電波がなくても叩ける。
  • ログインできた：スクワットマンが跳ねて起き、0.6秒でスプラッシュへ。
  • プライバシーポリシー：リリースまでに用意する（課題 privacy-policy）。
