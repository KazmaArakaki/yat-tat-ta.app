プライバシーポリシー↗

膝や腰が痛むとき、医師から運動を止められているときは、休んでください。食べてすぐで気分が悪いときは、少し時間をおいてから。

  • 目標回数：−と＋で5回ずつ。5〜100回。既定は20。叩いている途中で変えても、その記録は叩き始めたときの回数のまま。
  • 今日まだ通知：ON/OFF と時刻。既定は 21:00。OFF にすると時刻の行が薄くなる。
  • 使い方をもう一度：シートを閉じてチュートリアルを場面1から。練習は記録を動かさない。叩いている最中は押せない。
  • アカウント：中身は、Apple でログインしているかで替わる。匿名アカウントの人には「Appleで続ける」（iOS の標準のボタン）と「記録をすべて削除」。押すと Apple ID へ引き継ぐ。その Apple ID に別の記録があれば、確かめてから切り替える（このモックでもボタンで出る）。Apple でログイン中の人には「ログアウト」と「アカウントを削除」。どれも叩いている最中は押せない。決まりは機能：アカウント。
  • プライバシーポリシー：Safari でプライバシーポリシーを開く。端末の言語で日本語か英語のページ。
  • 注意書き：一番下に、見出しなしで常に出す。文面の決まりは 健康効果の書き方。
  • 閉じる：ホームに戻る。下へ引いても閉じる。
