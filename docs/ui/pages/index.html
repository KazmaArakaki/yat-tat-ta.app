ui / pages

画面

アプリの画面の見本です。画面はホーム1枚と、そこから出す設定シートだけ。どちらも起動した直後の状態をサンプルデータで描いています。

記録の一覧画面はありません。記録を取り消す仕組みを作らないので、一覧で見せて操作させるものがないからです（課題 undo-record）。

home

ホーム

連続記録の帯、完了連打のボタン、DPW と DT のカード。叩くと動く。

settings

設定シート

目標回数と今日まだ通知。ホームの歯車から開く。

today-records

今日の記録

今日の記録を並べ、左へスワイプで消す。連続記録の帯から開く。

画面の上に重ねるカードや帯（途切れたとき、休み券を使ったとき、通知の問いかけ）は、コンポーネントで状態ごとに見られます。
