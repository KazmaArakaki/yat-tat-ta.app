履歴

ホームの DPW か DT のカードを押すと、下から出すシートです。これまでの記録を、日付と時刻の上にスクワット隊の人形で並べます。背景の薄い面は、日ごとのドパと7日移動平均です。

このモックでは、グラフを横にドラッグするか、ホイールを回すと過去の日へ戻れます。人形を押すと、下にその記録が出ます。サンプルは30日分で、今日（10/6）は2件、休み券を使った日が2日あります。
