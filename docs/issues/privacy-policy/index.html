プライバシーポリシーと App Store のプライバシーの表示

優先度：高 状態：未着手

概要

記録を Firestore に置き、Apple のログインでアカウントを作るようになった。
リリースまでに、プライバシーポリシーを書いて公開し、App Store Connect のプライバシーの表示を埋める。

やること

  1. プライバシーポリシーを書く。集めるもの（Apple のログインで割り当てられる番号、スクワットの記録）、置き場所（Google の Firebase、東京）、使い道（記録を残して見せるだけ）、消し方（設定シートのアカウントの削除）。
  2. 公開する場所を決める。URL が要る。
  3. ログイン画面の「プライバシーポリシー」の行から開く。App Store Connect にも同じ URL を入れる。
  4. App Store Connect のプライバシーの表示を埋める。スクワットの回数を「フィットネス」、番号を「ユーザ ID」として、利用者に結びつくデータに申告することになりそうだが、区分は申請のときに Apple の説明で確かめる。

気をつけること

健康についての書き方は、プライバシーポリシーでも健康効果の書き方に従う。「健康のために記録を集める」のような書き方はしない。

優先度が高の理由
App Store の審査は、プライバシーポリシーの URL がないアプリを通さない。リリースの前に必ず要る。
先送りにした理由
アプリの作りは、ポリシーの文面を待たずに進められる。公開する場所を決めるのも、作りとは別の判断になる。
