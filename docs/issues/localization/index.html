概要

開発者は、アプリを 多言語展開 したいと考えている。
決まっているのは、アプリ名 Yat Tat Ta を全言語で同じ表記にすることだけ。

  1. a対応する言語

    最初に出す言語と、基準にする言語（開発言語）。

  2. b画面の文言の持ち方

    文言をコードに直接書かず、翻訳ファイル（Xcode の String Catalog など）に集める仕組み。あとから入れると、書いた文言を全部拾い直すことになる。

  3. cストアの説明文

    App Store Connect では、サブタイトル、説明文、スクリーンショットを言語ごとに登録できる。

ドパ〇〇の演出には「激熱」「PUSH」のような、日本のパチンコ文化に根ざした言葉が多い。訳すか、別の言葉に置き換えるかも、この課題の中で考える。
