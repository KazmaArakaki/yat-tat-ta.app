間違えて作った記録を取り消せるようにするか

優先度：低 状態：進行中

進行中 2026-10-06

作ることにした。連続記録の帯の左側から今日の記録のシートを開き、今日の1件を左へスワイプして消す。

今日の記録から取り消す　機能：今日の記録

概要

いまの作りでは、一度できた記録は消せない。
間違えて叩いてできた1件を、あとから取り消せるようにするかを決める。

取り消したくなる場面は、たとえば2つある。

  1. aポケットの中で触れた

    スクワットしていないのに数打が入り、60秒後に1件として閉じる。

  2. b勢いで次の連打を始めた

    フィナーレのあとの1.2秒を過ぎてから叩き、1件多くなる。

設計のときに考えた形は、画面下から今日の記録を開き、1件を左へスワイプして消すもの。消せるのは今日（午前4時区切り）の分だけにする。

作るときに、休み券の食い違いは心配しなくてよい。休み券は保存せず、記録を日付順にたどって毎回計算している。7日目の記録を消せば、その日にもらった休み券も、計算し直した結果から自然に消える。DT、DPW、連続記録も同じで、直すのは記録1件だけで済む。

優先度が低の理由
間違いの記録が残って困るのは本人だけ。ランキングも他人との比較もない。記録から全部を計算する作りなので、あとから足してもほかの作りに響かない。
先送りにした理由
2026-10-06 の本作りの設計で、開発者が今回は作らないと決めた。取り消しがなければ、記録を一覧で見せる画面も要らず、画面はホーム1枚で済む。使ってみて、間違いの記録が本当に起きるかを見てから決める。
