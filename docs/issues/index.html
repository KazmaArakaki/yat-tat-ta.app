サーバー

  • 開発用と本番用の Firebase を分け、App Check を入れる

    優先度：高

    いまは開発中のビルドも本番と同じデータベースに書く。利用者が0人のうちに分ける。

  • 起動のたびに全部の記録を読む費用

    優先度：低

    記録が増えるほど読み取りの回数が増える。1日3万回を超えたら、増えた分だけ読む形に変える。

  • プライバシーポリシーと App Store のプライバシーの表示

    完了 2026-10-07

    ポリシーとサポートのページを Firebase Hosting で公開し、アプリから開けるようにした。App Store Connect にも入れた。

アプリの中身

  • 多言語展開の進め方を決める

    完了 2026-10-06

    日本語と英語で同時に出す。声も演出の言葉も英語にした。それ以外の端末には英語で出す。

  • 間違えて作った記録を取り消せるようにするか

    完了 2026-10-06

    連続記録の帯から今日の記録を開き、今日の1件を左へスワイプして消せるようにした。

  • 演出を盛ったときの処理落ちを確かめる

    完了 2026-10-06

    計測モードで3回測った。指は遅れを感じず、切れていた声を直した。Core Animation のままで足りる。3回目を基準値にした。

  • 健康効果の書き方を決める

    完了 2026-10-06

    画面には書かない。ストアの説明文に、食後に体を動かす研究の話を1文だけ。注意書きは設定シートの一番下とストアに。

  • マナーモードで音を鳴らすか

    完了 2026-10-06

    マナーモードに従って黙る（.ambient）。ほかのアプリの音楽は止めない。

  • アプリ名を決める

    完了 2026-10-06

    Yat Tat Ta。ホーム画面も App Store も、全言語で同じ表記。
