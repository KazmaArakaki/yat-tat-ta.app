iOS アプリの土台を決める

優先度：高 状態：未着手

概要

本番アプリの Xcode プロジェクトを作る前に、4つ決める。
このうち (a) は、テスト用アプリがそのままでは iPhone に入らないという形で、もう表に出ている。

  1. a最小対応 iOS バージョン（Minimum Deployments）

    Xcode 27 の初期値は 27.0。テスト端末の iPhone 15 Pro は iOS 26.6.1 なので、そのままでは入らない。端末の iOS を上げるか、最小を 26 にするか。

  2. bXcode プロジェクトの置き場所

    リポジトリのどのディレクトリに置くか。

  3. cBundle Identifier

    アプリを識別する ID を何にするか。

  4. diPhone 専用に絞る

    Xcode 27 の新規 App は Mac と iPhone の両対応で作られる。iPhone だけにする設定を入れる。

優先度が高い理由
アプリを書き始める前に必要。
先送りにした理由
2026-10-06 のセッションは、環境が動くことの確認が目的だった。テスト用プロジェクトは捨てる前提。土台はアプリの中身を決めるときに一緒に決めたほうがよい。
