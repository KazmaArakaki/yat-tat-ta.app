アプリ名を決める

優先度：中 状態：未着手

概要

ホーム画面と App Store に出るアプリ名が、まだない。
いまはターゲット名 YatTatTa が仮の名前として表示される。

  1. aホーム画面の名前

    project.yml の INFOPLIST_KEY_CFBundleDisplayName で決まる。いつでも変えられる。

  2. bApp Store の名前

    App Store Connect で登録する。ほかのアプリと同じ名前は使えない。

Bundle Identifier（com.yat-tat-ta）とターゲット名は、アプリ名と別物なので変えなくてよい。

優先度が中の理由
仮の名前のままでも開発と実機確認はできる。TestFlight で人に配る前までに要る。
先送りにした理由
2026-10-06 の時点で、何を作るか（題材）が決まっていない。名前は題材と一緒に決める。
