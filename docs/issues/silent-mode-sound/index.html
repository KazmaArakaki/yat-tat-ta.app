マナーモードで音を鳴らすか

優先度：低 状態：完了 2026-10-06

概要

手触りの試作は、マナーモードの iPhone でも音を鳴らしている。
本作りでも鳴らすのか、マナーモードに従って黙るのかを決める。

  1. a鳴らす（いまの試作）

    音声セッションのカテゴリを .playback にする。音楽アプリと同じ扱い。電車の中で開いた人が、いきなり音を出してしまう。

  2. bマナーモードに従う

    カテゴリを .ambient にする。ゲームでよくある扱い。振動と光だけになったときに、手触りがどれだけ残るかが問題になる。

どちらでも、ほかのアプリの音楽を止めない（.mixWithOthers）かどうかも合わせて決める。試作は止めない設定にしている。

優先度が低の理由
設定1行で切り替えられる。あとから変えても、ほかの作りに響かない。
先送りにした理由
どこで使われるアプリかは、題材で変わる。2026-10-06 の時点で題材は未定。試作では「音が出ない」と迷わないことを優先した。
2026-10-06 追記：題材は毎食後スクワットに決まった。食後に限らず間食や夜食のあとにも、いつでも記録できる。職場や外で叩く場面がある（題材を決める）。2026-10-06 追記：b のマナーモードに従うに決めた。カテゴリは .ambient、ほかのアプリの音楽は止めない（.mixWithOthers）。決め手は、いつでも記録できること。職場で昼食のあとに叩けば、20個の音が事務所に響く。黙っても振動と光は残る（本作りの設計）。
